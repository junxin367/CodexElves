# 远程会话工具与关联会话

更新日期：2026-11-14。本文以当前工作区源码为依据，说明当前生效的入口、交互、数据来源、权限和缓存规则。源码规则不表示电脑上已经运行该版本；运行服务、Android 安装包与真机验收状态另行核对。

## 菜单入口与页面层级

PC 左侧会话列表的行菜单提供“打开独立窗口”。Windows 远程客户端在当前程序内创建新的会话窗口，PC 网页打开浏览器独立窗口；新窗口沿用同一来源的登录授权并定位到所选会话，隐藏左侧会话列表，保留完整的主会话、编辑区、会话菜单和右侧多标签面板。各窗口的标签和阅读位置分别维护，草稿沿用现有恢复机制，操作仍指向同一原生会话，不创建会话副本。主程序窗口关闭仍收进托盘，独立会话窗口关闭只销毁自身，不停止后台会话。手机与 Android 不增加此菜单项。

PC“文件”和“变更”列表中的文件支持右键菜单“在独立窗口中打开”。文件条目打开现有文件预览，变更条目打开对应仓库及暂存分区的差异预览；目录和不支持预览的文件不增加入口。新建页已选择项目时也可打开文件窗口。窗口通过原会话或项目接口重新读取内容，共用原有授权和预览组件，不启动聊天、不恢复输入回执，也不影响原会话和标签页。读取发现授权失效后清除窗口内容，用户可在原窗口重新登录后重试。独立预览沿用打开来源的主题、字体及文件字号。

远程会话右上角的“会话菜单”向下展开，顺序固定为：

1. **变更**。
2. **文件**。
3. **浏览器**。
4. **子智能体**分组。
5. **侧边会话**分组，标题右侧为新建加号。

前三项不另加“工具”标题。分组标题左对齐，使用较小字号；子智能体折叠按钮与侧边会话加号使用相同的标题操作区域。菜单支持键盘导航；手机和 PC 点击功能后均保持展开，再次点击图标关闭。手机还可点击菜单外的普通页面隐藏，但侧边会话页面中的点击不隐藏菜单。固定菜单不拦截页面点击及返回操作。

按钮触发的普通菜单、Select、模型菜单和会话菜单统一按可视区域的水平中线定位：按钮中心在左半边时，与按钮左边缘对齐并向右展开；否则与按钮右边缘对齐并向左展开，中线归右侧。缩放、平移后使用实际可视区域判断，视口边缘至少保留 8px。右键和长按菜单保留点击坐标锚点，命令/Skill 补全层保留输入框对齐，hover 提示保持原定位。

会话菜单继续向下间隔 10px。侧栏展开、收起及右侧面板调整时持续跟随按钮，跨过中线时同步切换水平对齐方式，关联会话页的布局动画也会同步更新；按钮隐藏、移除或移出视口后清理菜单。菜单关闭、挂起或页面进入后台时停止位置跟踪，恢复可见后重新对齐。

| 入口 | 当前行为与条件 |
| --- | --- |
| 变更 | 查看当前会话或新建会话所选项目的 Git 未提交变更；无目标、非 Git 目录或目录失效时显示对应说明 |
| 文件 | 浏览同一目标的项目文件；已有会话和已选择项目的新建页均可使用 |
| 浏览器 | 入口保留在菜单中；点击先检查当前线路包含 FRP，再调用 Android 浏览器能力。不满足 FRP 条件或不在支持该能力的 Android App 中时说明原因 |
| 子智能体 | 读取当前会话的原生子智能体后代关系，点击进入只读会话页 |
| 侧边会话 | 读取服务管理的所属主会话临时侧边；加号创建侧边会话，条目可打开或关闭 |

PC 网页和 Windows 远程 EXE 使用页面右侧的多标签面板，聊天与输入框保持可操作。会话菜单右侧提供独立的“打开标签页”按钮，面板展开后该开关仍保持在窗口右上角，功能改为“隐藏标签页”，不跟随会话菜单向左移动。标签栏不再提供“打开文件”加号和关闭整个面板的 `×`；文件、变更和侧边会话仍从会话菜单或正文引用打开。

隐藏面板只收起容器，保留已经打开的标签、当前页、滚动位置及侧边会话草稿，重新展开直接显示原页面，不重新加载或重建 iframe。隐藏等待创建的标签不会取消原操作，迟到成功只更新保留的标签，不自动重新展开面板。没有打开标签时显示入口说明。

PC 标签状态按会话分别保存在当前页面内存中；切换会话时隐藏原标签，切回后恢复该会话已打开的文件、变更、侧边会话及内容、选中项、面板显隐、调整宽度和标签滚动位置。侧边 iframe 留在原位置，不重新加载，草稿和阅读位置继续保留。新建页按所选项目分别保留。后台文件读取固定使用原会话或项目身份，旧页面不能在新会话打开标签；注销、更换设备授权或关闭整个页面时释放整组标签，刷新页面后也不恢复标签列表。客户端默认宽度及文件、变更只读缓存按下文各自规则保存。

PC 标签内容与主会话共用全窗口的背景底色、图片铺法及透明度。面板、嵌入文件/变更页面和侧边会话 iframe 的内容底层保持透明，背景图片只由主页面绘制一次；侧边页面不再单独读取或绘制背景图片。输入框、菜单、代码区等控件仍按同一套外观配色派生表面色。

PC 从侧边会话、文件或变更标签打开图片及视频时，使用主页面上的资源预览，按整个可视页面居中，不受右侧标签宽度限制。手机和 Android 保留整页资源预览。两端预览底板及边框透明，框内留白与外围共用一层深色半透明遮罩，最大宽度仍为 `90vw`、最大高度仍为 `80dvh`；图片等比适配，小图不主动放大。关闭预览返回原标签及阅读状态，切换或关闭来源侧边标签时结束其预览。侧边转交只接受同源且当前可见的所属 iframe，资源仍经过既有图片和视频校验。

文件列表、变更列表、文件内容、差异详情和侧边会话可同时保留多个标签，重复打开同一目标切回已有标签；不同仓库、暂存分区的同名差异分别显示。侧边会话保留独立的输入、滚动及实时状态，隐藏标签不自动确认已读。各标签自身的 `×` 和鼠标中键点击标签均用于关闭该页面，不关闭服务端会话；关闭当前标签后选择相邻项，关闭全部标签后恢复聊天宽度。

标签按可用空间自动收缩，最小宽度为 100px，最大沿用 220px；达到最小宽度后，鼠标滚轮可在标签栏上横向浏览全部标签，触控板横向滚动仍可使用。关闭按钮默认隐藏，仅在鼠标悬停于对应标签时显示，并保留原占位以避免标题跳动。

侧边会话确认正在执行时，标签前图标替换为旋转图标，执行结束、停止或等待用户处理时恢复会话图标。状态来自侧边页面已有的原生会话事件，隐藏标签及面板时也继续同步，不增加状态轮询；发送中、仅有排队消息或结果待确认不会自行显示执行图标。

拖动面板左侧分隔线调整宽度，当前会话保留自己的调整值，并以最近一次调整作为新会话面板的默认宽度；临时缩小窗口不会覆盖所选宽度。分隔线也支持方向键调整及 `Home` / `End`。标签栏支持方向键切换、`Home` / `End` 和 `Delete` 关闭当前标签，`Escape` 隐藏面板并保留页面。切换会话或新建项目保留各自标签，授权变更清理全部标签；关闭标签取消其未完成读取。

手机窄屏及 Android 容器继续使用独立整页，进入时从右向左滑入，右上角“返回”按层级退出：

- 会话 → 变更列表 → 差异详情 → 返回变更列表 → 返回会话。
- 会话 → 文件树 → 文件内容 → 返回文件树 → 返回会话。
- 从正文文件引用直接打开内容页时，返回原会话，不强制经过文件树。

子智能体和手机、Android 的侧边会话使用关联会话整页。页面隐藏左上侧栏按钮和连接状态，右上保留“会话菜单”及“返回”；子智能体可在标题区域显示模型和思考深度。PC 侧边会话使用右侧标签内的独立页面，外层标签提供名称，内页隐藏整段顶部标题、路径和按钮及主侧栏，文件和变更仍以该侧边会话为目标。专用 `/side-thread` 入口只允许同源页面嵌入，普通首页和 API 保持禁止嵌入；此入口需随网页资源一起更新远程服务程序。

进入关联会话前保存原会话草稿、已显示正文、展开状态和阅读位置。返回优先恢复这些内容，再静默读取最新状态。返回目标优先为打开该页的会话，否则为原生父会话；页面刷新后也会校验导航归属，避免误退到其他历史页面。

关联会话返回时，原页的不可交互临时副本向右退出，后方显示已恢复的父会话。动画为 220ms；减少动态效果或无法建立隔离样式时直接切换。快速导航会清理旧动画，不让旧页继续接收输入或覆盖当前页。

## 数据来源与可用性

远程 Codex 仅使用服务模式，网页没有运行模式开关。普通会话、子智能体和服务侧边会话由 `Harness` 统一路由；桌面已持有会话继续通过原生 IPC 协作，服务持有会话使用 app-server。侧边会话由服务独立创建和管理，不与桌面原生侧边标签共享。

| 能力 | 当前数据或执行来源 |
| --- | --- |
| 子智能体关系与正文 | app-server 的父子关系、历史及事件，或同一桌面持有者的只读 IPC 快照 |
| 侧边创建、输入、历史、关闭 | 服务的 `thread/fork` 临时分支、内存队列和内存投影 |
| 会话和项目工作目录 | 服务核验会话身份、项目目录及所属实例后读取 |
| Git 变更、项目目录及文件内容 | 确定工作目录后，由电脑端 Rust 模块读取 Git 或文件系统 |
| Android 浏览器页面与网络转发 | 手机 WebView、本地代理和已授权的电脑网络通道 |

所有读取校验设备授权；工作区读取前后还会核对授权。只读访问可以查看文件与变更，子智能体保持只读。写操作只派发一次；失败或结果未知保留原回执，不改走页面注入或另一条执行通道重发。WSL Claude 工作目录仅映射到会话所属发行版，不接受客户端指定项目根目录。

## Claude 离开期间回顾开关

在“设置 → 会话 → Claude”中选择 Claude 实例，切换“离开期间回顾”。开关与该实例原生 CLI `/config` 中的 `Session recap` 共用用户级 `settings.json` 的 `awaySummaryEnabled` 配置。连接或重新检测实例时，为尚未显式配置这一项的可用 Claude 实例自动写入 `false`，默认关闭回顾；已有的显式开启或关闭选择均保留，重复检测不覆盖。关闭后停止自动生成回顾，已经记录的回顾仍保留在历史中。

会话中的回顾消息沿用原生 `※ recap: <内容>` 前缀，不显示中文名称。

配置严格绑定所选实例的 WSL 发行版和用户；只修改这一项，保留模型、权限和其他设置。CLI 重新加载配置后生效，项目配置或启动参数中的同名设置优先。只读访问不自动写入默认值，也不能手动修改；初始化失败按实例提示具体原因，不虚报关闭或阻止其他实例检测。读取失败、配置被其他窗口修改或保存结果未知时提示重新读取，不自动重复保存。

WSL 配置通过所属用户的原生文件操作原子更新，保留原文件的 Linux 权限、所有者和扩展属性，新文件权限为 `0600`。不得用 Windows UNC 文件权限重建 Linux 配置，避免将原本仅本人可读写的配置扩大为其他用户可读。

## Claude 历史消息编辑

共享 Claude 会话在确认执行结束后，支持对原生可回退的历史用户消息“编辑并再次发送”，不限最后一条。执行、审批或原生弹窗等待期间不开放编辑；提交时核对原生历史头与消息 UUID，不停止任务或将编辑重发放入网页队列。

编辑通过原版 CLI 的 `/rewind` 只恢复对话，继续使用原会话 UUID 和后台，不改写 JSONL、不回退代码。原图随修改后的文字保留；内部摘要、控制命令和工具轮次内吸收的排队附件不伪造独立编辑节点。原生保留的旧分支退出当前网页正文和模型上下文，已发生的累计 Token 消耗保留。

回退后的新消息仍按原生受理证据显示。失败或结果未知时保留编辑内容和原回执，不重复回退、重发；缓存同步和子代理归属随当前分支更新。实现边界与验证范围见 [验收记录](validation/remote-claude-message-edit-20261113.md)。

## 子智能体

### 关系与列表

- 从原生子智能体后代快照读取关系，沿父链核对成员属于当前会话；不仅限于直接子节点。
- 识别依据包括原生父会话、`subAgent/subagent.thread_spawn` 和子智能体来源标记。普通 fork 或工具输出中的任意文本不构成子智能体身份。
- 使用原生排序结果，将 `active`、`waiting` 放在活动列表，将 `done` 放在已完成列表；各列表保持原生排序后的相对顺序。
- 活动条目显示名称和经过时间。菜单打开时用本地计时更新时间，不为每秒数字变化请求列表。
- 子智能体分组默认展开；点击标题或右侧折叠按钮可整体收起，已完成区也随之隐藏。
- 有完成项时显示最多四个彩色图标和“数量 完成”按钮。完成明细默认收起，点击完成行可独立展开并打开对应子智能体。
- 没有条目时不显示“暂无子智能体”。读取未完成、缓存尚待同步或读取失败时，会显示相应的同步/失败状态，不能将未知结果当成空列表。
- 子智能体部分读取失败时保留可用的侧边数据；有既有子智能体快照时继续展示，并标明它是上次结果。

### 只读与生命周期

子智能体由 Codex 原生机制创建，远程同步其名称、关系、状态和正文。进入子智能体后隐藏输入及写操作区域；原生动作入口也拒绝对子智能体发送、停止、编辑、排队、修改目标或回复审批等写入。返回主会话后恢复主会话自己的权限。

生命周期按原生 `ephemeral` 属性区分：明确为临时的子智能体读取原生内存历史；非临时子智能体可走普通历史分页。不能把所有子智能体统一当作临时，也不能为了打开已失效的临时子智能体另建会话。

## 侧边会话

### 服务关系与创建

侧边列表来自当前服务内存中的父子登记。通过 `thread/fork` 创建 `ephemeral=true` 分支，继承父会话上下文和工作目录，正文只展示创建后的输入与输出。临时侧边不能再创建下一层侧边，也不进入普通主会话列表。

创建时追加侧边专用开发者指令，并通过 `thread/inject_items` 在继承历史之后写入任务边界；只有边界初始化成功才登记为可发送会话。主会话历史只供参考，侧边不继续其中的任务、不操作子代理；工作区修改和跨会话发送需要边界后的用户明确授权。内部边界不进入正文，初始化失败不降级、不重复注入，并尝试释放本次分支；释放结果未知时保留待核对状态。

模型与思考深度取创建时主会话的当前选择，权限保存尚未完成时先等待。侧边独立保留继承的原生权限，编辑区隐藏权限选择按钮，服务端拒绝侧边权限修改；主会话之后的权限变化不改写已有侧边。原生返回的自定义批准策略、沙盒限制和命名权限配置保持原样，不折算成更宽松的预设。

加号要求已选有效主会话、当前连接可用、可写、服务声明侧边能力，且没有同一主会话尚待确认的创建请求。PC 在右侧标签显示创建状态，手机和 Android 使用可返回的整页。关闭等待页只取消自动打开，不撤销已提交创建；迟到成功登记到原主会话。

PC 快捷键保持 Windows/Linux 的 `Ctrl+Alt+S` 和 macOS 的 `⌘⌥S`，与菜单使用相同权限和防重规则。按键长按、输入法组合和 AltGr 不触发创建。

### 名称与输入

新建时显示默认名称；首条已接受且包含有效文字的用户消息按前 15 个 Unicode 码点命名。图片、空文字、待提交输入和压缩输入不参与命名，已有自定义名不覆盖。

模型与思考深度在创建时继承，之后独立选择，只用于后续新发送。空闲直接发送，确认执行中才进入该侧边的内存队列；停止、失败或送达未知后暂停续发。引导、编辑、删除和重排沿用服务规则，不将队列回执提前显示为正文。

临时侧边不提供已发送消息编辑、持续目标、置顶或持久队列。正文、输入及设置仅保存在当前服务内存，服务进程重启后不可恢复。完整边界见 [服务模式独立侧边会话](remote-service-mode.md#服务模式独立侧边会话)。

### 运行与未读

- 侧边正在执行且不处于等待状态时，条目右侧显示转圈。
- 执行结束且原生标记未读时显示蓝点；运行中或等待用户处理时不显示完成未读提示。转圈与蓝点不同时出现。
- 当前主会话存在符合条件的未读侧边时，菜单入口左下方图形变为蓝色圆点；其他主会话的未读不影响它。
- 成功打开侧边后，在正文已初始化、页面可见、连接和权限有效等条件下调用原生已读接口；确认后同步清理本地菜单及侧栏标记。点击条目本身不等于已读成功。
- 仍有其他未读侧边时入口蓝点保留；新一轮执行完成后可再次产生未读。
- 主会话列表聚合自身及侧边的执行、等待与未读信息。等待状态优先；没有等待且自身或侧边仍执行时显示运行状态，不能只检查主会话本身是否执行。

### 关闭、过期与未知结果

长按或右键侧边条目可打开只含“关闭会话”的菜单；滑动取消长按，长按结束不会顺带进入会话。关闭需要确认，提示临时侧边及内容无法恢复。

关闭时核对会话 ID、父关系和服务内存身份，先停止活动轮次，再取消订阅并释放临时分支。不能用该入口关闭普通主会话。

| 情况 | 当前处理 |
| --- | --- |
| 远程主动关闭成功，或收到明确的原生关闭事件/关联列表移除证据 | 移除条目及对应缓存；正在查看该侧边时返回来源主会话 |
| 读取准确的当前侧边 ID 得到过期或缺失证据 | 保留已显示正文，隐藏输入框，在底部显示“侧边会话已过期”和只可查看已保留消息的说明；用户可手动返回 |
| 普通网络失败、授权错误或其他会话 ID 的错误 | 不据此判定当前侧边过期 |
| 创建或关闭结果为 `pending` | 保留原请求，连接有效且页面可见时按既有节奏核对原回执 |
| 结果未知、派发后超时或连接变化 | 保留原请求及防重复操作状态，提供查询原回执；不重新创建或关闭 |

引擎连接结束或临时分支卸载后，保留服务最后收到的正文并进入只读过期状态，不调用 `resume` 或自动创建来恢复执行。没有保留正文时明确显示不可读取，不伪装为空历史。

创建和关闭使用稳定的 `Idempotency-Key`，操作记录按授权和父会话隔离。同主会话重复触发复用已有记录。页面恢复后仍核对原请求，但不凭恢复记录自动跳入新侧边。Codex 已丢失的临时会话不会由远程另行持久恢复。

## 变更

变更范围为当前会话实际工作目录所在的 Git 仓库，包括当前 worktree；新建页使用所选项目的工作目录。不能用同项目其他 checkout 代替。

| 分区 | 比较内容 |
| --- | --- |
| 已暂存 `staged` | HEAD 与 index |
| 未暂存 `unstaged` | index 与工作目录 |
| 未跟踪 `untracked` | 作为新增内容展示 |

新增、修改、删除、重命名、复制、冲突和类型变化按实际 Git 状态展示；同一文件可以同时出现在已暂存和未暂存分区。仅执行权限等元数据不同、没有内容变化的修改项被过滤，二进制内容变化仍保留。实现批量核对各分区内容，不修改仓库 Git 配置。

页面顶部显示项目路径，搜索框固定在列表上方，仅文件列表滚动。搜索匹配当前变更路径及原路径，不读取文件正文；分组默认展开，可分别折叠。搜索期间的临时折叠和普通列表的折叠状态分别处理。

文件行显示文件名、目录或原路径和状态。桌面点击后新开差异标签，保留列表筛选、折叠和滚动；手机点击进入独立详情，返回时恢复列表。再次打开先显示缓存，再核对最新版本，没有独立手动刷新按钮。

- 文本差异显示增删颜色、增删统计及单列有效行号，支持自动换行；文件头和 hunk 不占空白行号列。
- PNG、JPEG、GIF、WebP 及通过内置 SVG 内容检查的资源提供前后预览；新增或删除明确表示一侧不存在。
- 其他二进制、特殊文件或不能预览的内容显示类型、大小与原因，不伪造文本差异。
- 文件已不属于所选分区时返回状态变化错误，重新读取列表，不继续展示为当前有效详情。
- 变更列表最多 2000 项，Git status 输出读取上限 2 MiB；每侧文件读取及图片预览上限 4 MiB，文本 diff 输出上限 4 MiB。超限返回截断标记或原因，不宣称内容完整。

此页只读，不提供暂存、还原、提交或推送。

## 文件与正文引用

### 项目文件树

Git 项目以当前 worktree 根目录为边界；非 Git 项目以会话实际工作目录为边界。目录在原列表展开/收起，不进入项目外磁盘。

界面先列文件夹，再按名称进行中文环境下的自然排序，数字参与数值比较、大小写不敏感；路径用于相同名称的后续排序。图标按目录、代码、配置、文档、图片等类型区分。

搜索按项目相对文件路径匹配，不搜索正文。服务端从项目根递归查找，跳过 `.git`、`node_modules`、`.pnpm`、`target`、`dist`、`build`、`temp`、`test-results`、`.idea` 等目录；目录浏览本身与项目搜索不是同一筛选范围。单目录和搜索结果最多 2000 项，超限显示说明。

### 内容查看

- UTF-8 文本可显示行号、基础语法着色及自动换行。
- `.md`、`.mdx` 默认使用 Markdown 预览，可切换源码；指定行号时直接显示源码并定位。其他文本默认显示源码。
- PNG、JPEG、GIF、WebP 及通过内置检查的 SVG 可预览并放大；SVG 检查不通过时显示不支持预览。
- 二进制和特殊文件显示说明；单文件读取上限为 4 MiB，超限不加载完整内容。
- 返回时保留文件树搜索、展开及滚动，内容页保留源码/预览、换行及阅读位置。PC 切换会话或新建项目时保留各自的标签文件页；手机整页切换目标时仍清理原文件页。更换授权时全部清理，旧请求不能写回新目标。

### 正文文件引用与浏览器查看

正文中的本地文件链接、可识别的行内代码路径和普通文件路径可转为文件引用。显示简洁文件名，完整路径保留在提示中；代码块和公网链接不强行转换。

短按打开文件页；长按、右键或相应键盘操作打开“文件 / 浏览器”菜单。`:行号`、`#L行号` 等已识别行号会带入源码定位。

本地文件的浏览器地址为当前授权下的 `/api/workspace/view/<threadId>/<path>`，需要已有会话。普通浏览器可打开该同源地址；Android 使用内置浏览器。这个文件引用入口不执行通用“浏览器”菜单的 FRP 前置检查；从侧边打开时使用其来源主会话的工作区身份。HTML 响应使用隔离 sandbox，允许页面脚本但禁止连接请求、嵌套页面及表单提交等能力；它与文件页的源码查看不是同一执行方式。

客户端可提交项目内的相对路径或绝对文件路径，但不能指定项目根目录。服务端拒绝目录穿越、项目外路径、`.git` 元数据、符号链接、Windows 重解析点及不支持的特殊文件，并核验最终打开文件仍位于授权目录内。

文件树与内容页不提供文件编辑、删除、上传、暂存或提交；复制文本、图片预览及浏览器查看使用各自现有入口。

## Android 浏览器

浏览器由 Android 独立进程中的 WebView 在手机本地渲染。首页提供网址/搜索输入；页面顶部为标题和“返回”，底部保留导航、地址、刷新及设置。返回会话可保留当前浏览器进程内页面和网页历史。

网络按每个请求的目标地址分流：

- 普通公网域名与公网 IP 使用手机网络。
- 回环、本地及内网 IP、本地域名、单标签内网主机，以及设置中的域名及其子域名，通过已授权的电脑网络转发。
- HTML、资源、接口、重定向和 WebSocket 分别判断目标，不通过失败后的自动换路改变分流规则。
- HTTPS 通过 CONNECT 保留端到端证书验证，不在代理中解密网页。

设置按远程服务地址保存。电脑转发使用手机 loopback 代理与随机认证口令，代理认证不转发给目标网站。浏览器使用独立 WebView 数据目录；打开时同步当前远程服务同源授权所需 Cookie，不向浏览器页面注入主会话原生桥。授权撤销、服务切换、注销或服务停止后，旧授权的转发连接失效。

详细 Android 运行与权限规则见 [Android 指南](android.md)。

## 缓存、刷新与迟到结果

| 数据 | 当前保存方式与边界 |
| --- | --- |
| 关联菜单 | 按设备、授权 scope 和主会话缓存；内存最多 32 个主会话，成功结果新鲜度 30 秒；事件可使其提前失效 |
| 菜单持久快照 | `session-menu` v3 仅保存明确 `ephemeral=false` 的子智能体及其完成数；侧边列表为空，恢复后仍须同步；身份未知或临时成员不写入 |
| 子智能体折叠 | 整个分组默认展开、完成明细默认收起；两个状态只保存在当前页面的对应主会话菜单项 |
| 侧边及临时子智能体正文、设置与位置 | 在本页内存复用，不写入持久只读缓存 |
| PC 右侧标签面板 | 按设备、授权及会话/新建项目保留标签 DOM、内容、选中项、显隐、宽度和标签滚动；切回直接复用，授权变化或页面关闭后释放 |
| 变更列表、差异及页面状态 | 按授权和会话/项目隔离，复用内存与 IndexedDB 只读缓存；详情还按分区和路径区分 |
| 文件树和文件内容 | 每个文件页的内存缓存，响应最多 24 项且总计 16 MiB，页面位置最多 64 项；PC 保留在所属会话标签内，手机整页切换目标时清空，不写入变更页的持久缓存 |

菜单先展示可用缓存，再按事件或访问新鲜度核对。相同数据不重建条目，计时只更新原时间节点。创建、关闭、已读确认会更新缓存版本，早于操作的查询不能把旧条目或旧未读状态写回来。

关联列表请求本身没有统一“加载中”占位；具体子智能体集合仍可显示读取未完成、上次结果或失败状态。首次没有缓存且请求失败时显示失败提示，有缓存时保留它。

变更和文件详情使用 `ifRevision` 核对内容；不能用列表中的 `M` 状态代替文件内容版本。版本相同返回小响应并保留内容、DOM、图片和位置。普通网络错误可保留上次显示并说明缓存状态；授权或目录/文件身份失效时删除相应旧数据。

共享 IndexedDB 只读缓存默认保留 7 天，总计最多 32 MiB、64 条、单条 6 MiB；缓存失败或超限会降级。缓存只供展示，不提供操作权限、原生执行身份或发送成功证据。更完整的模型、目标、队列与正文缓存规则见 [缓存说明](remote-cache.md)。

## 接口与传输

| 接口 | 关键输入 | 当前输出或行为 |
| --- | --- | --- |
| `POST /api/workspace/changes` | `threadId` 或 `projectId`，可选 `ifRevision` | `root/files/truncated/revision`；条目包含 `path`、可选 `oldPath`、`status/section` |
| `POST /api/workspace/change` | 同上，另加 `path/section` | `kind/diff/before/after/truncated/revision`；`kind` 为 `text/image/binary/unsupported` |
| `POST /api/workspace/files` | `threadId` 或 `projectId`、`path`，可选 `query/ifRevision` | 当前目录或项目搜索的 `root/path/files/truncated/revision` |
| `POST /api/workspace/file` | `threadId` 或 `projectId`、`path`，可选 `ifRevision` | 文件 `kind/size/text` 或 `mime/dataUrl`，及 `truncated/revision` |
| `GET /api/workspace/view/<threadId>/<path>` | 已有会话和项目内路径 | 经授权的原始文件响应；HTML 使用隔离策略，响应不缓存 |
| `POST /api/read/relatedThreads` | 主会话 `threadId` | `subagents/completedSubagents/completedSubagentCount/sideThreads/canCreateSideThread` 及子智能体读取完整性状态 |
| `POST /api/action/createSideThread` | 主会话 `threadId`、可选 `model/reasoningEffort`，稳定 `Idempotency-Key`；权限由服务端继承 | 操作回执；成功结果包含新 `threadId/parentThreadId`，可包含首屏 `thread` |
| `POST /api/action/closeSideThread` | 侧边 `threadId/parentThreadId`，稳定 `Idempotency-Key` | 操作回执；成功结果为同一会话及 `closed=true` |
| `GET /api/receipts/<id>` | 原操作 ID | 查询 `pending/completed/failed/unknown`，不重复执行原操作 |
| `GET /api/browser/tunnel` | 当前设备授权及合法的浏览器转发协议消息 | WebSocket 转发电脑网络，不是任意会话操作或磁盘路径读取接口 |

四个工作区 POST 接口属于安全读取。当前传输会按可用线路排序，失败或慢请求在符合条件时顺序尝试另一条授权线路，最多两路；不会把动作写入发到两路竞速。侧边创建、关闭等动作只派发一次，结果不确定后查询原回执。

`revision` 是完整可见响应的 SHA-256，包含目录及内容；`ifRevision` 必须为 64 位小写十六进制。相同时返回 HTTP 200 的 `{ok:true,notModified:true,revision,root}`，不附带完整数据。私有响应使用 `Cache-Control: no-store`，展示缓存由客户端显式管理；服务器仍实时读取并检查当前状态。

工作区确定目录后的服务端读取处理上限为 40 秒，单次 Git 命令上限为 10 秒；对应网页读取上限为 45 秒。超时表示本次读取未完成，不证明会话已删除或侧边已过期。
