# 远程会话工具菜单与二级页面：需求与开发任务

更新日期：2026-10-23。

## 已确定的需求

远程会话页面右上角的“会话工具”按钮向下展开菜单，“文件”入口紧邻“变更”下方，随后保留其他工具及“子智能体”和“侧边会话”分类，不显示“工具”标题；分类标题使用较小字号并左对齐。选择后，独立页面从右向左滑入；各页面右上角统一显示“返回”按钮。桌面和手机使用同一页面层级，不使用右侧栏或页签。

返回会话时保留原会话正文、草稿和滚动位置。切换会话不能把上一会话的变更结果显示到新会话。系统返回操作遵循当前页面层级。

子代理和侧边会话返回时，先恢复缓存中的主会话正文、草稿和滚动位置，再让不可交互的子页临时副本以 220ms 的节奏向右滑出，动画后方直接显示主会话，与变更页一致。临时副本隔离在独立 DOM 树中，保留子页原来的滚动位置和输入显示，不参与主会话的选择器、消息更新或操作。副本使用已加载规则构造样式表，遵守现有 `style-src 'self'` 安全策略。右上角返回、浏览器后退和 Android 返回使用同一处理；退出期间暂停交互，快速前进可以取消尚未完成的退出并移除临时副本。系统开启“减少动态效果”、不支持构造样式表或无法读取当前样式时直接切换，不等待动画。

### 子智能体

- 从当前主会话的 Codex 原生子代理关系读取列表，不把普通 fork 或工具输出中的任意文本当作子代理。
- 保持 Codex 原生列表的顺序，展示仍在执行或等待的子智能体名称与执行时间。已完成信息以彩色图标与“12 完成”形式展示，不单独提供折叠入口。
- “子智能体”标题右侧显示折叠图标，与“侧边会话”标题右侧加号共用尺寸、间距和对齐布局。默认展开；点击标题或折叠图标时，整个子智能体列表和已完成信息一起收起或展开，其他分类不受影响。
- 分组折叠状态在当前页面中按授权与主会话分别保留，静默刷新不改变状态；没有已完成项时不显示完成行，也不添加空列表描述。数量、条目文字和图标随字号设置缩放。
- 子智能体由 Codex 原生代理机制创建，远程只同步原生关系、名称、状态和消息，不另建 fork、侧边聊天或持久登记。生命周期跟随原生 `ephemeral` 属性；临时子智能体的历史读取原生内存消息，不调用磁盘历史分页或尝试恢复已关闭的原生会话。
- 点击条目后使用主会话已有的正文、工具记录、图片及历史分页展示。页面只读，隐藏输入和写操作控件；发送、停止、编辑、队列、目标、审批等操作也在原生操作入口拒绝。
- 子代理页隐藏主会话顶部左、右按钮，右上角仅显示“返回”。只读状态独立于设备权限，返回后主会话仍可正常操作。
- 打开列表时核对状态；执行时间在本地更新，不为每秒计时重新请求列表。原生状态变化时合并刷新列表。

### 侧边会话

- 分类标题共用横向布局。“侧边会话”标题右侧显示无背景的小加号图标，与标题垂直居中，保留至少 12px 间距，图标不收缩；不使用绝对定位或手机端专属位置修正。下方按 Codex 原生侧边标签顺序显示当前主会话的侧边会话。
- 2026-10-21 最新约定：直接使用 Codex 原生侧边会话创建入口，共用其标签、上下文继承、权限、指令边界及生命周期。当前本机原生入口创建临时会话；不再建立独立持久登记，也不为了保留会话改写 Codex 左侧列表。
- 远程菜单和侧边页面统一沿用 Codex 原生侧边标签名称，默认显示“Side chat”“Side chat 2”等标题；原生标签暂时没有名称时回退为“Side chat”。名称从原生标签或会话摘要读取，不从首条消息正文派生，也不修改主会话或子代理标题。
- 点击新建后立即滑入创建中页面，右上角可返回主会话。创建成功回执携带新会话首屏快照，直接恢复会话设置和空聊天区，省去紧接着的会话信息与历史读取；旧服务未提供快照时沿用原读取流程。
- 创建中返回保留主会话草稿和阅读位置；随后收到成功回执只更新侧边列表，不自动切走主会话。重复点击复用原请求，结果未知时停止等待动画并提示查询原回执，不再次创建。
- 新建聊天区为空，继承内容的模型可见范围由原生创建流程决定。临时会话的正文直接读取 Codex 内存消息并分页，不调用它不支持的磁盘历史分页接口。
- 桌面原生侧边标签与远程菜单显示同一批会话；创建、关闭、标题和未读状态同步，远程名称按原生标签标题展示。桌面未加载对应主会话时，经用户确认，远程创建允许通过原生导航打开主会话；已加载时复用其页面上下文。
- 关闭使用原生标签关闭流程，结束并丢弃临时会话。远程关闭前提示不可恢复，桌面关闭时远程同步移除；正在查看的侧边会话被关闭时返回主会话。Codex 重启后不单独恢复原生已经丢失的侧边会话。
- 此前旧实现已经保存的持久分支不自动删除或迁移，也不再按旧登记隐藏。
- 侧边会话页面复用主会话正文和输入功能，隐藏原顶部左、右按钮，右上角仅显示“返回”。各会话分别保留草稿、正文、展开状态和阅读位置。
- 侧边会话正在执行时，菜单条目名称右侧显示转圈状态；完成、停止或等待用户审批与输入时移除。状态复用原生会话运行信息，沿已有会话事件静默更新；完成未读后显示原有蓝点，转圈与蓝点不同时显示。
- 当前主会话存在尚未关闭、执行完成且未读的侧边会话时，菜单按钮只将左下角方块替换为蓝色实心圆点，其他三个方块保持原样；对应侧边会话条目右侧显示蓝色小点。运行中、等待回复、已读或已关闭的侧边会话不显示完成未读提示。
- 进入侧边会话后使用原生已读接口清除该会话的未读状态，并同步清理菜单缓存；刷新后仍保持已读。如果还有其他未读侧边会话，入口蓝点继续显示。新一轮执行完成后可再次显示蓝点，其他主会话的侧边未读不影响当前入口。
- 长按或右键点击侧边会话条目，弹出仅含“关闭会话”的菜单；滑动取消长按，长按结束不能再触发进入会话。
- 新建和关闭沿用设备写权限及请求回执。创建结果不明时查询原请求，不自动再次创建。关闭核对原生标签、内存父关系与请求双方 ID；关闭已派发后的超时或连接变化保留未知结果，不能利用该接口关闭普通主会话。

### 变更

- “当前项目”指当前会话实际工作目录所在的 Git 仓库，包括当前 worktree，不用同项目其他 checkout 代替。
- 展示未提交文件，区分暂存、未暂存、未跟踪状态，覆盖新增、修改、删除、重命名及冲突。
- 三个分组标题可点击展开或收起，默认展开；支持键盘操作，并按当前会话或项目记住状态。
- 当前项目路径放在顶部栏；搜索框固定在列表上方，仅文件列表滚动。没有手动刷新按钮，再次进入先显示缓存，再后台核对是否变化；详情返回保留原列表状态。
- 文件行突出文件名，下一行显示所属目录或原路径，右侧显示状态；支持按文件名或路径筛选当前变更。
- 点击文件查看该状态对应的差异：暂存区比较 HEAD 与 index，未暂存区比较 index 与工作目录，未跟踪文件显示新增内容。
- 已暂存和未暂存的修改文件按各自分区核对内容；只有执行权限等元数据变化、内容没有增删时不列为变更文件。二进制内容变化正常显示，新增、删除、重命名和冲突继续按文件状态展示。已暂存修改比较内容哈希，未暂存修改在单次只读查询中忽略执行权限探测；每个分区批量核对，不逐文件生成 diff，也不修改仓库配置。
- 文件详情是独立页面，从右向左滑入；右上角返回回到变更列表，保留筛选和列表滚动位置。变更列表右上角返回回到会话。
- 文本以带行号、增删颜色的 diff 展示；图片提供修改前后预览，新增或删除时明确标注一侧不存在。其他二进制资源显示类型、大小与无法文本比较的说明。
- 文件行采用约 48px 的最小高度，字号增大时自然撑高。搜索、文件行、图标、差异及辅助文字跟随字号设置；diff 使用单列有效行号，文件头和 hunk 不保留空白行号占位。
- 无会话、非 Git 目录、工作目录失效、无变更、读取失败、大文件截断均有明确提示。
- 该功能只读，不包含暂存、还原、提交、推送或任意路径浏览。

### 文件

- 右上角菜单在“变更”下方显示“文件”。进入后使用与变更一致的整页滑入和右上角返回。
- 根目录由当前会话或新建会话所选项目确定：Git 项目使用当前 worktree 根目录，非 Git 项目使用会话实际工作目录。目录按项目原始读取顺序展示，文件夹在当前列表中展开或收起；搜索框按项目相对路径搜索文件，不提供项目外磁盘浏览。文件图标按文件夹、代码、配置、文档、图片、样式、脚本、锁文件及常见语言类型区分。
- 点击文件进入独立内容页。UTF-8 文本可查看带行号的源码，Markdown 默认按文档排版并可切换源码，PNG/JPEG/GIF/WebP 支持图片预览。其他二进制格式显示大小和不支持预览的说明，不执行 HTML、SVG 或脚本。
- 目录返回、文件返回保留筛选及滚动；从正文直接进入文件时，返回回到原会话位置。当前会话内使用有界内存缓存和内容版本核对，切换会话或授权时清除旧内容，迟到响应不能写回新会话。
- 正文中的本地 Markdown 文件链接、行内代码文件路径及可明确识别的普通文件路径显示为蓝色文件名，完整路径保留在提示中；短按打开文件页，长按或右键显示“文件”和“浏览器”入口。带 `:行号` 或 `#L行号` 的引用打开源码并定位。浏览器入口通过当前会话鉴权的工作区地址打开本地文件，HTML 使用隔离沙箱响应；代码块和公网链接保持原有显示。
- 只允许当前项目内的相对路径或绝对路径；拒绝目录穿越、项目外路径、`.git` 元数据、符号链接及 Windows 重解析点内容。沿用当前设备鉴权，读取前后复核授权，只读设备也能查看。
- 单目录最多展示 2000 项，文本和文本差异最多预览 4 MiB，图片及完整文件读取最多 4 MiB；超过限制明确提示。本功能不包含编辑、删除、上传、下载、暂存或提交。
- 接口为 `POST /api/workspace/files`（目录）和 `POST /api/workspace/file`（内容），使用 `threadId` 或 `projectId`、`path` 和可选 `ifRevision`；客户端不提供项目根目录。

### App 缓存

- 菜单中的子智能体列表、执行时间、已完成明细与数量和侧边会话列表按授权与主会话独立缓存；切换回来先显示缓存，再按事件或访问时的新鲜度静默核对。内存保留 32 个主会话菜单。临时子智能体及侧边会话的列表、正文和阅读位置不写入持久只读缓存，正常原生持久会话继续复用 IndexedDB 缓存。
- 菜单读取期间不显示加载文案；有缓存先显示缓存，首次没有缓存则在读取完成后补充列表和数量。菜单数据未变化时不重建条目，后台更新不清空数量或弹错误。创建、关闭和已读成功后同步修正缓存，迟到请求及旧授权结果不能回填已失效的数据。
- 列表、文本差异、图片预览及页面状态使用当前授权的只读缓存；键区分已有会话与新建会话所选项目，详情再区分分组和路径。退出或更换授权时由既有缓存清理流程隔离数据。
- 有缓存时先显示，再以 `ifRevision` 核对；未变化只返回小型确认响应，保留原 DOM、图片和位置，不重新下载完整 diff 或图片。每次打开详情单独核对内容版本，不以列表仍显示 `M` 判断内容未变。
- 持久缓存复用 IndexedDB 只读缓存库，整体上限 32 MiB、单条 6 MiB、64 条记录，默认保存 7 天；超出上限或本地存储不可用时降级，不阻塞使用。内存另作有界复用。
- 目录失效、文件不再属于当前变更或授权失效时清除相应旧缓存；普通网络错误可以保留上次内容，但明确显示缓存状态。缓存只用于展示，不能替代服务端授权和路径校验。

### 浏览器入口

2026-10-23 按新的远程会话需求恢复 Android 浏览器入口。会话菜单中“浏览器”紧邻“变更”下方；点击后由 Android 独立进程中的 WebView 打开浏览器页面，网页在手机本地渲染，顶部左侧为“浏览器”、右侧为“返回”，浏览器设置位于底部。

默认使用手机网络。`localhost`、回环及内网 IP、本地域名、单标签内网主机和用户在浏览器设置中添加的域名及其子域名，通过已授权的电脑网络转发；公网 IP 和普通公网域名保持手机直连。网页 HTML、图片、脚本、接口、重定向和 WebSocket 按各自目标地址逐请求分流，不通过失败重试改变路线。

浏览器设置按远程服务地址保存在 Android 设备中。电脑转发使用专用手机 loopback 代理和随机口令，代理认证头不会发送给目标网站；远程设备撤销、切换服务、主会话注销或服务停止时，旧浏览器页面和转发连接失效。浏览器使用独立 WebView 数据目录，不共享主会话 Cookie 存储；打开浏览器时由当前授权能力同步同源设备 Cookie，不同步原生桥。

## 接口约定

所有接口沿当前登录入口单路发送，不进入双线路写入竞速。

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `POST /api/workspace/changes` | `threadId`；新建会话可用 `projectId`；可选 `ifRevision` | `ok`、`root`、`files`、`truncated`、`revision` |
| `POST /api/workspace/change` | 同上，及 `path`、`section` | `ok`、`root`、`path`、`section`、`kind`、`diff`、`before`、`after`、`truncated`、`revision` |
| `POST /api/read/relatedThreads` | `threadId` | `ok`、`threadId`、`subagents`、`completedSubagentCount`、`sideThreads`、`canCreateSideThread` |
| `POST /api/action/createSideThread` | 主会话 `threadId`，稳定的 `Idempotency-Key` | 操作回执；成功结果包含新 `threadId`、`parentThreadId` 及可选首屏快照 `thread` |
| `POST /api/action/closeSideThread` | 侧会话 `threadId`、`parentThreadId`，稳定的 `Idempotency-Key` | 操作回执；成功结果包含 `closed:true` |

变更条目字段为 `path`、可选 `oldPath`、`status`、`section`。`section` 为 `staged`、`unstaged`、`untracked`，同一文件可能同时出现在暂存与未暂存列表。详情 `kind` 为 `text`、`image`、`binary` 或 `unsupported`；图片侧为 `{exists,mime,size,dataUrl}`，不存在的一侧 `exists:false`。工作目录由服务端使用原生会话或项目标识解析，客户端不得直接提供绝对目录。

`revision` 为完整可见响应（含仓库目录）的 SHA-256，`ifRevision` 仅接受 64 位小写十六进制。匹配时返回 HTTP 200 的 `{ok:true,notModified:true,revision,root}`，不附带列表、diff 或图片；未提供条件时仍返回全量响应。两种响应均保留 `Cache-Control: no-store`，私有缓存由 App 显式管理。服务端仍读取并校验当前状态；本次优化减少网络传输与重复渲染，不引入 Git 文件监听或服务端持久缓存。

浏览器电脑网络转发使用已授权的 `GET /api/browser/tunnel` WebSocket；该接口只接受当前设备授权和有效目标首帧，不接受网页直接指定本机路径或任意远程会话操作。

## 任务分工与验收

主代理负责需求范围、接口决策、共享文件接线、审查与最终验收。子代理不得改写其他任务拥有的文件；接口调整先交主代理协调。

| 任务 | 负责人 | 独占修改范围 | 验收结果 | 当前状态 |
| --- | --- | --- | --- | --- |
| Git 变更读取 | `workspace_backend` | `remote_access/workspace.rs` | 暂存/未暂存/新增/删除/重命名、图片前后、路径与输出限额 | 完成 |
| 内容版本协商 | `workspace_backend` 与主代理 | `remote_access/workspace.rs`、`remote_access.rs` | 列表及详情的 `ifRevision`、版本校验、未变化时省略正文 | 完成，真实服务已验证 |
| 分组折叠及 App 缓存 | `browser_minimal_ui` 与主代理 | `session-tools.js`、样式、`app.js`、`recovery-store.js` | 折叠及滚动恢复、目标隔离、版本核对、DOM 与图片复用 | 完成，服务及验收 APK 已更新 |
| 缓存独立复核 | `network_browser_review` | 只读审查 | 迟到请求、授权切换、冷启动读取和缓存容量边界 | PASS，已确认问题均闭环 |
