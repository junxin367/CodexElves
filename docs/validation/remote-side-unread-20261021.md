# 侧边会话完成未读蓝点验收

日期：2026-10-21。

## 行为

当前主会话存在执行完成且未读、尚未关闭的侧边会话时，菜单按钮左下角的方块替换为蓝色实心圆点，其他三个方块保持原尺寸、描边和位置。菜单中对应条目的右侧显示蓝色小点，颜色与现有主会话未读标记一致，条目小点随字号按比例缩放。

进入会话后调用既有原生已读接口并清理菜单缓存；只清除所进入会话的标记。有其他未读条目时保留入口蓝点，全部查看后恢复四个方块。新一轮执行完成后重新提示，刷新页面后沿用原生已读结果。

原生 `sidebar` 响应额外提供当前未关闭的完成未读侧边会话与父会话关系，`relatedThreads` 的侧边条目增加 `hasUnreadTurn`。入口借助现有侧栏及事件刷新更新，菜单未打开时也能提示，不另增定时轮询。持久展示缓存不保存该实时状态。
