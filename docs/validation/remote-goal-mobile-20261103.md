# 手机目标编辑与状态按钮验收

日期：2026-11-03。范围仅为本轮目标弹窗高度、展开后的暂停/开始及删除入口。

## 实现

- 手机编辑弹窗靠上显示，上限取440px、60svh和可视区域可用高度的较小值。长内容在输入框内部滚动，底部操作栏不随正文增长；使用已有视口事件适配键盘，不增加轮询。
- 目标展开后，编辑图标下方纵向显示暂停/开始及删除；折叠时保留原编辑入口。
- 复用现有`updateGoal`和原回执处理，以可选`operation`兼容旧编辑请求。状态切换调用原生`setThreadGoalStatus`，删除调用`clearThreadGoal`并确认目标为空。没有用会重新激活目标的`setThreadGoal`代替状态切换。
- 暂停只暂停目标推进，不额外调用停止生成；删除保留会话消息。预算/用量受限时不强行启动，未知结果不重复提交。
