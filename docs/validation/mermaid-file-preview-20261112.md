# 文件 Markdown 的 Mermaid 预览

日期：2026-11-12。最终正式资源 `2026111225`。

## 实现

文件预览复用会话的 Markdown、Mermaid、安全净化、图表缓存和渲染队列。每个滚动容器独立观察接近视口的图表，打开文件不取消会话中尚未显示的图表。主题更新使用文件自己的布局事务；切换文件、源码或关闭预览时释放观察器，旧任务不能写回新内容。

保留图表／源码切换、源码复制及整份文件源码模式。错误语法或图表资源不可用时保留可读源码。沿用已有严格 Mermaid 配置及 SVG 清洗规则。

正式验证还发现首次目录尚未返回时，搜索的两个空 root 被误判为缓存命中，随后读取不存在的缓存。已增加真实缓存存在检查，覆盖目录响应为 null 和 undefined 的回归。
