# 远程页面统一 Select

用户要求新增设置复用主题设置已有的 Select，选中项仅显示勾选标记，整项只在鼠标悬停时高亮。

## 统一入口

`assets/remote-access/select.js` 提供 `createSelectComponent`。`app.js` 只创建一次组件实例，复用已有弹层服务；值同步、选项更新、用户提交、禁用判断和 `change` 事件由组件处理。

业务设置使用 `selectControl(id, label, options, value)` 创建控件，通过 `onchange` 接收用户选择。程序同步使用 `setSelectValue`，动态数据使用 `setSelectOptions`；这两种同步不触发 `change`。用户提交由 `commitSelectValue` 验证选项存在且未禁用，值改变时只派发一次事件。新增设置不再使用原生 `<select>` 或另写弹层。

覆盖设置中的九个 Select：主题、图片铺法、每项目会话数、两种字重，以及自定义指令的类型、环境、作用范围和项目。新建页的项目与会话类型也复用同一组件。

现有弹层继续统一负责定位、搜索、键盘导航、模态层级和焦点恢复。动态环境暂不可用时保留原选中目标和草稿，显示禁用条目；所有正常环境均可进入指令选项。设置中按 Escape 或 Android 返回键时，先关闭下拉层，再响应下一次页面返回。

## 样式和资源

移除 Select 选中项的整行填色和额外加粗，保留右侧 `✓`。鼠标悬停时使用统一悬停色，键盘焦点使用轮廓；触屏不产生悬停填色。项目与类型菜单不再分别定义选中背景。

新模块同步加入正式资源清单、静态路由、本机预览、PWA 必需资源和 Android 内置网页清单。本机预览仅补充转发两个固定设置接口，保持原有登录和权限核对。
