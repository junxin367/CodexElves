# 侧边会话上下文与主列表隔离验收

日期：2026-10-21（北京时间）。

## 调整结果

- 新建侧边会话继续通过 Codex 原生持久 fork 继承上下文，并启用原生 `sideConversation` 标记。原生创建过程自动加入上下文边界；没有通过重新发送主会话历史来模拟继承。
- 创建时仅记录继承轮次的 ID。远程聊天区、历史分页、消息编辑元数据及记录事件均排除这些轮次；上下文本身仍保留在原生会话内。侧边会话创建后产生的独立消息继续正常展示和分页。
- 旧侧边登记首次打开时补记边界。原生轮次开始时间早于创建回调的属于继承历史；缺少开始时间时，通过与原生主会话轮次 ID 的对应关系确认，不把无法确认的独立轮次隐藏。
- 远程主列表对全部已登记侧边会话过滤，覆盖最近、项目和置顶区域。关闭只改变菜单列表状态，历史仍保留且不会重新混入主列表。桌面采用原生侧边标记，并在原生桥重新加载时根据持久登记恢复。
- 旧侧边聊天缓存不再恢复继承的主会话记录，新缓存携带侧边历史展示版本。主会话缓存和独立消息内容不作全量清空。
