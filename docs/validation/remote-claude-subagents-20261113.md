# Claude 原生子代理接入验收

日期：2026-11-13。网页资源修订号：`2026111305`。

## 接入范围

- 主会话的原生 `Agent` / `Task` 调用显示为子代理卡片，可进入现有只读详情。
- 会话菜单显示本会话使用的子代理、执行状态、耗时及已完成分组；不会将后台 Bash 任务计为子代理。
- 子代理身份绑定原主会话和 WSL 实例；记录读取、模型和项目目录不改投其他实例。
- 详情保留原任务、续聊输入、回复和工具结果。fork 的继承启动记录不重复显示；原生协调消息在该只读子视图中按实际输入分轮。
- 原生任务通知只更新状态，不形成用户消息；用户手写相同文本仍保留。
- 续聊受理后旧完成通知失效，同一 ID 可以重新显示执行中。缺失记录返回读取失败，不能以空历史撤掉已显示内容。
- 直接打开或重新进入子代理 URL 时，从后端确认的父会话关系恢复只读布局与返回入口。

## 执行与性能边界

子代理仍由原版 Claude 执行，保持原有工具、MCP、Skills、Hooks 和权限机制。查看记录不启动或恢复子代理；服务端拒绝对只读子代理的发送、停止、审批、设置和删除操作。侧边会话能力保持独立。

原生文件读取仅在查看菜单或详情时触发，不加入主会话发送、回执或 250ms 接收轮询。菜单沿用每秒只读核对，子代理详情每两秒补读；页面隐藏、离开或返回主会话后停止相关补读。正文按原生已写入记录更新，不承诺逐 Token 转发。
