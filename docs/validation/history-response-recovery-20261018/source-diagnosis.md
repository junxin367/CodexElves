# 远程会话历史响应失败：源码诊断与修复验证

验证日期：2026-10-18。此报告记录源码与隔离函数验证；真实浏览器 HTTP 验证由主代理另行保存。

## RCA 结论

- 状态：部分确认。客户端缺陷已用修复前后的相同生产函数验证；截图所对应手机请求的原始响应尚未取得，不能断言现场一定发生了正文截断或解码失败。
- 现象：手机截图已有正文和队列，顶栏为“断开·自动重连”，提示“会话历史返回格式无效”。
- 直接原因：`readHistoryPage()` 收到的值不含数组 `data` 时抛出此提示。已有正文可以来自当前页面已加载内容或会话内存缓存，这不代表本次历史读取成功。
- 已证实的代码根因：公共 `api()` 把成功 HTTP 响应的正文读取或 JSON 解析异常替换为 `{message:"HTTP 200"}` 并返回。历史读取随后把这个伪成功对象当作历史协议错误；发送动作还会将该对象当作成功路径处理，提前清除待确认回执和草稿。
- 系统性根因：尚未确认。现有公共 API 入口确实把 HTTP 成功和正文成功混为一个结果，但未取得足以判断该缺陷如何进入版本、为何未被既有流程发现的历史证据。
- 关键因果链：200 响应的正文读取/解析拒绝 → 原 `api()` 吞掉异常并返回缺少 `data` 的普通对象 → `readHistoryPage()` 抛出“会话历史返回格式无效”。修复后同一输入进入正文失败分支，只读历史最多立即重读一次，耗尽后保留内容并显示真实失败类别。

## 已排除解释

- “无历史记录的正常成功响应不带 `data`”：当前原生成功路径构建数组，正常空数组用例也成功；没有发现此种合法返回路径。
- “原生分页校验失败会合法返回 200 且没有 `data`”：原生失败返回 `ok:false`，Rust `native_result()` 将其转成非 2xx 错误。
- “该提示足以证明网络正文截断”：完整且合法的 JSON 若不含数组 `data` 也会产生同样提示；现场缺少原始响应，不能排除此分支。
- “增加全局断线或重发动作即可恢复”：历史读取失败不构成连接断线证据；写请求回包失败也不证明动作未执行。修复未采用这两种行为。

## 异常状态溯源

- 适用约束：对于 `/api/read/history`，成功读取的结果应当是该接口的历史页对象，`data` 为轮次数组或同轮消息数组；正常空历史使用 `[]`。对于写动作，只有确认原请求结果后才清除未确认草稿和回执，不能以缺少回执的结果证明提交完成。
- 约束依据及状态：原生历史接口的两种返回契约、项目关于历史保留和原 ID 回执核对的说明（`docs/remote-access.md:47`、`:49`、`:51`、`:754`），以及本任务明确要求；接口合同在隔离用例中已验证，现场是否命中正文失败前提未知。
- 本次运行前提命中判定：隔离复现命中；手机现场无法判定。
- 场景命中证据：使用原生 `Response` 对截断正文执行 `json()` 触发解析失败；注入正文运输/解码错误验证拒绝路径。运输/解码用例是隔离错误模拟，不是手机抓包。
- 值判断：隔离复现中，原 `api()` 自行构造的 `{message:"HTTP 200"}` 违反历史成功返回合同；手机现场值未知。
- 实际来源与传播路径：模拟成功 HTTP 响应 → `response.json()` 拒绝 → 原 `api()` 的 catch 构造替代对象 → `readHistoryPage()` 消费。
- 最后满足合同的状态 → 首次违反点：在正文未成功读取时尚无可用历史页；首次越过失败边界的位置是 `api()` 将异常转换为成功返回值。
- 调查边界与未知上游：手机网络、接入隧道、gzip 正文、WebView 与服务实际返回内容仍缺少请求级证据。

## 修复与防复发

- `api()`：2xx 正文读取或 JSON 解析失败必须抛出 `responseReadFailed:true`，使用固定提示，不回显正文原文或解析错误中的敏感片段。写动作同时标记 `outcomeUnknown:true`，继续走原请求回执核对。
- 非 2xx：非 JSON、`null`、原始值或非字符串 `message` 均保留 HTTP 状态；401 的当前设备认证处理不变，403 不误判为认证失效。
- `readHistoryPage()`：只对 `responseReadFailed` 立即再读取一次。两次使用同一请求正文、会话、游标和外层取消控制器；没有增加无证据支持的等待延迟。
- 不自动重试：完整 JSON 结构错误、非 2xx、普通 fetch 网络拒绝、超时和取消。切会话、离页、删除后也不重试、不接受旧结果。
- 同轮分页归属校验前移到修改历史和事件之前，错误页不污染当前内容。
- 重试耗尽后保留历史正文、分页游标及已读缓存，暂停自动调度并保留原有显式重试入口；不把失败转换为空历史。
- 系统性防线：本次使用隔离故障注入证明公共 API 的成功与失败边界；临时验证文件按仓库约定清理，未擅自添加永久测试。
