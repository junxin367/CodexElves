# 表格原始 / 紧凑布局与自动换行

## 用户要求与实现

- 表格信息栏右侧顺序为“自动换行”“原始布局 / 紧凑布局”。布局按钮按用户后续要求与 Markdown“源码 / 预览”保持一致，文字表示点击后的目标模式，不显示选中高亮；换行按钮仍通过按下状态表示开关。
- 按用户最终要求，初次打开默认使用紧凑布局、关闭自动换行；按钮显示“原始布局”用于手动切换。页码、工作表、布局和换行选择跟随当前文件缓存；返回重开会恢复，切换会话或设备授权清空。
- 信息行仍为 30px，行数仍与文件大小同一行。为了在窄屏保留两个新控件，表格翻页使用带“上一页 / 下一页”无障碍标签的箭头；空间不足时行数省略，完整范围保留在标题属性。
- 手机行号栏按用户最新要求从 35px 起，根据整张表最大行号位数自动加宽，水平、垂直居中；列标继续为 26px。

## 尺寸与换行规则

| 模式 | 列宽 | 行高 |
| --- | --- | --- |
| 原始布局 | 使用文件显式列宽或默认列宽，单列最多 480px；没有元数据时回退 120px | XLSX 显式行高或默认行高，缺省 20px |
| 紧凑布局 | 测量实际字体、字号、字重及文字内容，单列 48–480px | 按当前内容自然增减，不沿用文件预留的空白高度 |

- 原始列宽仍按 Excel 字符宽度 `× 7 + 5px` 近似换算；行高按 pt `× 4/3` 转为像素并取整。行高限制为 1–2048px，窄列允许小于紧凑模式最小值；非法数值回退默认。
- 宽度上限针对单列；整张表可横向滚动。原始宽列超过上限时，即使内容较多也保持 480px。
- 关闭自动换行时不折行；原始模式保留文件行高，超出内容由单元格裁切。开启后按当前列宽换行，并允许行高增大，原始行高作为下限，避免上限裁窄后文字丢失。
- 紧凑列宽按整个已读取工作表计算，翻页不跳变；横向合并标题约束整个跨度，不能单独撑宽 A 列。阅读字号变化会同比影响测量宽度，但最终仍封顶 480px。
- 合并、背景色、文字样式和默认数据读取限额继续保留；行高用稀疏映射读取，不按声明的百万行范围分配矩形。
- CSV/TSV/ODS 缺少本次协议的原始尺寸字段时仍可读取，原始模式使用回退值，紧凑模式按内容计算。未扩展为完整 Office 排版或隐藏行列还原。
