# 远程办公文件在线预览

日期：2026-11-10。

## 能力范围

远程会话正文中的文件链接和“文件”页使用相同的内容页，新增：

| 格式 | 在线读取 |
| --- | --- |
| XLSX、XLSM、XLTX | 工作表切换、原始行号和列标、已保存的单元格值及日期、表格翻页 |
| CSV、TSV（UTF-8） | 保留字符串前导零，处理引号、逗号及字段内换行 |
| ODS | 多工作表及有界的重复行列展开 |
| DOCX、ODT | 标题、段落、换行、表格 |
| PPTX | 按演示文稿中的实际页序读取各页文字 |
| PDF | 按页读取可提取的文字；扫描件不提供 OCR |

这是只读内容预览。后续表格布局修复增加了 XLSX 合并区域、列宽、背景色、字号、文字颜色、粗斜体、下划线及对齐；文档仍以正文为主，不还原 Office 的完整排版、图表和嵌入图片。公式显示文件中已保存的值，不重新计算；宏和外部链接不执行。XLS、DOC、PPT 等旧版二进制格式给出另存为现代格式的提示。具体见 `remote-spreadsheet-layout-20261110.md`。

## 实现

- 在电脑端解析文件，返回结构化文字及表格，不向第三方预览服务上传文件。
- 沿用 `/api/workspace/file` 的设备授权、原生会话工作目录、路径边界、符号链接限制、读取前后校验、响应版本和授权复核。
- `document_preview.rs` 负责格式识别和提取，`session-files.js` 负责结构校验及 DOM 展示，`style.css` 负责表格内部滚动和文档阅读样式。
- 表格和文档的内容均通过 `textContent` 显示，文件内的 HTML 不变成脚本、图片或外部请求。
- 输入沿用 4 MiB 文件预览限额；Office 压缩包最多 4096 个成员、解压大小合计 32 MiB、单个成员 16 MiB，XML 禁止 DTD。
- 表格最多 20 张工作表，每表最多 1000 个有内容的行、100 列，总计 10 万单元格；正文总量 1 MiB，单个单元格 16 KiB。超限显示截断提示。
- XLSX 按单元格流式读取，不按稀疏表格声明的巨大矩形范围分配内存；在调用解析器前核对共享文本计数。
- 手机每页仅渲染 100 行。返回和重新打开同一文件时保留工作表、页码及原有阅读位置；切换会话或授权继续清空旧上下文。
- 网页资源编号更新为 `2026111003`，后台构建标识为 `diag-20261110-document-preview-r20`；原生桥保留问答修复版本 137。
