# Claude 模型别名与推理等级

日期：2026-11-12。正式资源 `2026111226`。

## 原因与修复

已有目录包含 `opus` → `claude-opus-5-5` 的 `resolvedModel` 对应关系及五档推理等级；历史会话保存完整模型 ID。页面和后端原先只匹配目录的模型值，导致当前模型被误判为目录未提供，推理等级不可选。

前端当前模型、选中状态、等级及新建模型记忆现在使用同一身份匹配。精确值优先，Claude 才使用原生明确报告的 `resolvedModel`；Codex 保留精确匹配。后端校验采用相同规则。

重选同一模型或在别名与完整 ID 间切换时保留当前等级。切换为其他模型不继承旧等级；显式空值仍恢复默认。不为未报告的模型或等级推断能力。
