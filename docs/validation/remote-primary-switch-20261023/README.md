# zrok / FRP 主入口切换开发验收

日期：2026-10-23。交付状态：源码与本机隔离验证通过；未部署到当前真实远程服务，未进行 FRP 公网会话或 Android 真机验收。

最新界面修订已同步原型与实际 React 页面：标签位于「公网入口」标题右侧，使用小写 `frp`；地址改称「固定公网地址」；证书、私钥及 HTTPS 接入方式控件移除。第一行顺序为服务器地址、Token、服务端口、公网映射端口，两个端口输入框均为 80px 且隐藏上下箭头。主链路操作结果统一显示在按钮左侧，替换默认说明，不再额外弹窗；成功、警告、失败只用文字区分，无背景和边框。此前“高级模式显示证书控件”的界面用例已失效。

## 已实现

- 公网入口使用 zrok / FRP 面包屑。查看表单不切换生效入口，两份配置独立保存。
- 默认使用服务商提供的 HTTPS 地址，无需用户拥有服务商域名或上传证书；界面不提供本机证书及私钥控件。
- 没有 HTTPS 地址时可保存配置、测试 TCP 隧道；不能直接设为会话主入口。
- FRP 候选入口只开放随机回源校验及匿名 401 检查。入口验证成功后切换，失败保留原主入口；不接管外部手动启动的 frpc。
- 使用独立的候选配置和生效配置，支持重启恢复、停止服务时保存下次主入口。更改正在使用的 FRP 配置时，先切回 zrok 后再应用。
- zrok 绑定与主入口切换共用操作锁；停止或更改远程服务配置会使正在进行的验证失效。
- ngrok 隧道实现没有修改。协调层改为跟随所选主入口，保持现有通道凭据、选路、写入去重和事件机制。
- Android 原生代码未修改；静态核对确认当前主地址支持带端口的 HTTPS Origin，同源请求继续走原规则。

## 界面遗漏检查与修复

本轮仅调整管理器组件、审核原型和说明文档，没有修改隧道、ngrok 实现或 Android 代码。

- 主链路操作在按钮左侧显示结果后，不再重复弹出成功或错误通知；「测试访问」及主链路复制操作也使用该文字区域。
- 缺少 HTTPS 入口的测试结果显示警告；格式不合法的固定公网地址禁止应用，保存时提示具体要求。
- 启停远程服务或切换配置标签后清除旧操作结果。原型停用时显示「保存配置」，不再假报已完成公网验证；停用时禁止测试 zrok。
- 实际 React 页面验证了停用保存、仅隧道可用、切换成功、切换失败保留原入口、当前入口测试和键盘切换；原型验证了成功、失败及停用保存。以上均使用模拟后端。
- 在 1200、920、800、400px 视口下，FRP 表单及操作行无横向溢出；提示仍位于按钮左侧，背景透明、边框为零。两个端口输入框计算宽度均为 80px，外观为 `textfield`。

本轮记录见 `ui-review-checks.json`，原型截图见 `ui-review.png`。旧布局截图和证书控件用例仅作为历史记录，不代表当前界面。类型检查、原型脚本语法检查及差异空白检查通过。
