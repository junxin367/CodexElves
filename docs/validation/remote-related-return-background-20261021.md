# 关联会话返回时显示主会话背景

日期：2026-10-21（北京时间）。

## 问题与修复

原侧边会话和子智能体复用主聊天容器。返回时先将这个容器向右滑出，等待动画结束后才恢复主会话；动画后方因此只有页面底色。“变更”页使用独立覆盖层，主会话一直留在下方，所以没有该问题。

本次调整：

- 返回开始时保存子页的临时显示副本，立即按原缓存逻辑恢复真实主会话的正文、草稿、展开状态和阅读位置。
- 副本在独立 Shadow DOM 中复用当前样式，保留原来的输入显示和滚动位置；其中的 ID 不进入主文档，不影响主会话的选择器、消息更新或操作。通过 `CSSStyleSheet.replaceSync` 和 `adoptedStyleSheets` 应用已加载规则，不插入内联样式元素，保持现有 `style-src 'self'` 限制。
- 只让副本执行 220ms 的向右滑出动画，真实主会话保持原位。副本禁止交互并从辅助功能树中隐藏，动画期间主会话也暂时禁止操作。
- 动画结束、取消、超时或被新的导航取代时移除副本并恢复交互。沿用原有会话版本及授权校验，迟到的返回操作不能覆盖新页面。
- 减少动画模式、不支持构造样式表或无法读取当前样式时直接切换，不创建临时副本。
