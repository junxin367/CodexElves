- 会话菜单中“文件”紧邻“变更”下方，保留工作区同期新增的浏览器及其他菜单功能。
- 项目目录逐层浏览，文件进入独立内页；支持文本源码、行号定位、Markdown 阅读与源码切换、常见图片预览。
- 正文中的本地 Markdown 链接、行内代码路径和可识别的普通文件路径显示蓝色文件名，点击进入相同内容页。
- 返回保留目录筛选、阅读位置和会话草稿；切换会话使旧文件导航失效，取消旧请求并清除旧内容。

49 项检查通过：
