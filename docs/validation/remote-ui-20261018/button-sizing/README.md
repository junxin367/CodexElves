## 效果复核

`button-preview.html` 为可独立打开的对照页，直接嵌入本轮修改前后 CSS 与生产 SVG。按钮只展示样式，不执行实际业务操作。页面可切换浅深主题，可显示外框辅助线；默认不显示辅助线。Android 原生行仅列资源尺寸，不伪装成真机截图。

浏览器已逐项测量 11 类网页按钮，深色和浅色各 11 项均满足约束；详见 `button-measurements.json`、`button-light-measurements.json`。图片查看弹窗使用生产 `openImagePreview()` 函数、生产 CSS 和附件校验函数验证，手机 390px 视口下外框 32×32、SVG 16×16，四边均为 8px；点击关闭和 Escape 均正常关闭。

后续按用户要求将队列拖动图标从 14px 调整为 16px，外框仍为 28px，每侧留白为 6px。上面的两份尺寸 JSON 保留首轮验证快照；最新手柄尺寸见上级目录 `context-tooltip-and-handle.json`，对照页已同步更新。
