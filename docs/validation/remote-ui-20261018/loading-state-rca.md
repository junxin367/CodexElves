# 历史答复前残留加载提示的定位与修复

## RCA 结论

- 状态：**部分确认**。两个前端机制缺陷已用源函数最小复现确认并修复；截图当时的实际网络请求目标不可追溯，因此不把某一种请求类型写成截图的唯一原因。
- 现象：历史用户输入之后、已完成答复之前，在“用时 25分56秒”上方出现独立“加载中…”。
- 直接原因：`syncHistoryButtons()` 原先在 `historyLoadingTurnId` 为空时，把全部历史分页入口都标成“加载中…”。读取最新页、读取更早轮次时，这个值都为空，未指向的单轮历史入口也会被错标。
- 根因：共享的 `historyLoading` 只区分是否有读取和可选轮次 ID，没有保留最新页与跨轮旧页的目标差异。
- 系统性根因：完成活动的分页入口由消息主列表直接渲染，而已加载的活动由 `renderActivity()` 折叠。分页入口没有跟随活动的展开边界，真实补页也会在已完成正文之前呈现为独立加载行。
- 关键因果链：本轮超过消息单页大小 → 最新 40 条加首条用户输入的上下文投影已可展示最终答复 → `itemsNextCursor` 保留缺页入口 → 入口独立放在完成活动之前 → 任意没有轮次目标的历史读取会将其错标为加载中；真正的本轮补页也呈现为独立加载行。

## 已排除解释

- 候选解释：Markdown 格式加载遗留了这个独立提示。
  - 排除证据：两种提示的文本、节点类型和写入模块不同；最小复现没有启动 Markdown 依赖也能重现同样位置和文案。
- 候选解释：存在 `itemsNextCursor` 就代表最终答复仍未完成。
  - 排除证据：原生分页对较长的已完成轮次也返回游标；目标轮次存在完成事件和最终答复。
- 候选解释：必须删掉分页提示才能去除独立加载行。
  - 排除证据：修正后入口仍在活动明细内，展开、自动补页、手动重试及耗尽移除均通过。

## 异常状态溯源

- 适用约束：在已完成最终答复已经显示时，本轮较早活动的读取状态必须属于活动明细；在读取最新页或跨轮旧页时，未被请求的本轮历史入口不得显示正在加载。
- 约束依据及状态：用户第 8 项及主代理的明确处理边界；已确认。不得删除必要历史分页、活动轮次提示，也不得把缺页误判为完整。
- 本次运行前提命中判定：源函数最小复现命中；原截图当时网络请求目标无法判定。
- 场景命中证据：合成完成轮次包含可见最终答复、用户输入上下文、活动尾页和有效旧页游标。
- 值判断：修改前的无关入口“加载中…”违反约束；截图中游标是否有效、当时是否正在真正补页不能单凭截图判定。
- 值的实际来源与传播路径：原生 `thread/items/list` 的 `nextCursor` → `enrichHistoryTurn()` 的 `itemsNextCursor` → `mergeHistoryTurn()` → `renderMessages()` 入口 → `syncHistoryButtons()` 文案。
- 最后满足约束的状态 → 首次约束违反点：原生游标表示缺页，语义成立；前端渲染时把完成活动入口放在折叠边界之外，刷新时又用空轮次目标更新所有按钮。
- 调查边界与未知上游：未修改原生分页接口和游标；没有截图时刻的 DOM、待完成请求或网络记录。

## 修复与防复发

- 直接修复：历史按钮文案只跟随其实际请求目标；互斥期间仍禁用全部历史按钮。
- 根因修复：保留 `historyLoadingOlder` 区分最新读取与跨轮旧页读取；已完成最终答复的本轮入口由活动明细持有，折叠时不再独立悬在正文前。
- 系统性防线：活动展开触发已有自动调度；入口关闭时不补取不可见的活动；游标耗尽后清除入口；活动、被中断轮次和仅有 commentary 的轮次继续保留必要外部提示。
- 验证范围：最新读取、跨轮分页、单轮分页、完成活动归属、展开自动调度、失败手动重试、44 条合并无重复且最终正文保留、空活动、仅有最终答复的部分轮次、中断和 commentary、切换会话旧响应隔离。

## 浏览器集成步骤

1. 在隔离服务中将 `loading-state-fixture.json` 的 `latestResponse` 作为历史接口结果，thread ID 与所选会话一致，线程状态为 idle。
2. 首屏应依次可见用户气泡、折叠的“用时 25分56秒”、最终正文；活动入口在折叠的 `.activity-body` 内，主列表没有独立加载行；不应自动读取该隐藏活动的旧页。
3. 刷新最新页并延迟回包。完成轮次的旧页入口不得被错标为“加载中…”；最终正文保持存在。
4. 展开“用时…”，旧页入口可见时应自动请求 `{turnId:"completed-turn", itemCursor:"older:completed-turn"}`，仅该入口显示加载中。
5. 回包 `olderItemsResponse`。本轮旧页入口移除；原来 3 条与新增 2 条按 ID 合并，最终正文保留。
6. 再用同一夹具令单轮旧页请求失败。入口应恢复可点击，自动请求暂停；点击可重试，成功后移除。
7. 验证有 `historyCursor` 的跨轮分页、`emptyActiveTurn` 的“正在思考”、`emptyCompletedTurn` 无误加载、快速切会话旧响应隔离。
8. 延迟 Markdown 模块与正文图片。格式加载提示、图片占位和布局恢复走现有模块，应在其完成后消失；本次未修改这些模块。
