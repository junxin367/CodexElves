## 网页运行验证

- 使用 `http://127.0.0.1:1462`、`http://127.0.0.1:1463` 的临时合成服务。所有会话与 API 写操作均为内存夹具，没有发送真实会话消息。
- 320、390、768、1280px 屏宽分别检查 12、14、18px 字号，共 12 组。均无页面横向溢出，功能区起点与添加按钮起点相同，模型按钮未与发送按钮重叠。
- 320px 目标模式下，目标按钮位于第一行，模型按钮位于第二行，草稿保持；切回普通模式正常。
- 完成轮次的旧活动未加载时，分页按钮位于折叠的 `details.activity-group` 内，浏览器判定不可见。展开后模拟 503，入口与最终正文保留；刷新最新页只禁用按钮，不改为“加载中…”；手动补页时显示加载，完成后入口为零，活动记录从一条增为两条，最终正文仍只有一份。
- 提取当前生产函数的加载状态局部回归为 11/11 通过，涵盖空轮次、活动轮次、中断、展开调度和切换会话后的旧响应；JSON 中记录的源码哈希与最终候选一致。
- 控制台未发现脚本错误。`node --check assets/remote-access/app.js` 和 `git diff --check` 通过。
- Chrome 扩展未开启本地文件网址权限，不能通过自动文件选择完成上传；附件样式与移除使用实际附件组件和预置合成图片验证，不属于文件上传链路验收。
- 截图对应公网地址在本次取证时返回 `zrok bad gateway`，未取得该运行实例修复后的证据，也未重启正式服务。
