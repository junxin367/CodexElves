# 带图队列引导兼容

日期：2026-11-12。网页资源 `2026111230`，原生桥版本 `143`。

## 原因与修复

服务端队列保存 `image`，原生准备器可能将同一图片转换为 `localImage`。原校验只接受结构相同的输入，因此在提交前拒绝正常的带图引导。

已读取本机安装包中 `OoLr.K` 图片输入转换函数，将不含用户数据的函数原文和 SHA-256 固定在测试夹具中。原生优先使用附件的 `localPath`；没有本地路径时，内联图片保留为 `image`，文件来源转换为 `localImage`，`file://` 前缀移除后解码路径。

新比较仅用于引导准备结果与原服务端输入。每个转换必须在同一消息的附件上下文中找到唯一来源与唯一绝对路径，并保持原输入位置。未声明本地对应关系的内联图片、远程 URL、相对路径、无效转义、歧义来源或路径均不能据此放行。正文、文本标记、显式图片细节、未知字段、消息身份、恢复上下文和目标轮次继续严格核对；不同准备分支的输入仍使用原来的严格比较。

没有改写原队列图片或另发消息。确定性拒绝保留原队列，不自动重发；原生已发送但丢失回执时仍保留未知状态。诊断继续只记录布尔值和数量，不记录正文、图片路径、URL 或图片内容。
