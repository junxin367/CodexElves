2026-10-18：网页与安卓原生登录页已同步调整，图标和 `CodexElves` 标题按内容宽度作为一组水平居中。

- 网页登录页和连接恢复页使用同一个 `.pair-brand` 布局。保留图标尺寸、标题字号及头部间距；说明文字独占下一行、左对齐，窄屏可以自然换行。
