# 会话实例独立设置

用户要求将同一类型在不同运行环境中的安装实例分别列出和启用，并保留未来增加会话类型的扩展入口。

## 实现

- `remote_access/instances.rs` 注册类型名称、检测命令、本机检测开关、适配器就绪情况与连接方式。本机检测开关与执行适配器独立声明；当前暂停本机 Claude 检测，WSL 检测保持原规则。环境检测根据注册表收集安装位置，不执行模型任务。所有发行版使用同一套接入规则，不按具体名称增加权限限制。
- WSL 继承 Windows PATH 时，通过只读文件头及同名 `cmd` / `bat` / `exe` 标记排除 Windows 程序和 npm 启动脚本，避免将同一本机安装重复显示为 WSL 实例；共享磁盘中的真实 Linux ELF 保留。
- 实例标识由类型、WSL 发行版和用户确定，发行版名称不区分大小写；本机使用 `<类型>:local`。程序升级、路径变化和进程重启不重置实例开关。
- 设置按类型分组，逐个显示实际实例、安装位置、接入状态与独立开关。偏好保存在当前浏览器或 App，关闭实例不停止原生任务，允许全部关闭。
- 旧类型偏好只迁移到此前的默认实例，新检测实例默认关闭。已保存会话所在环境暂不可用时保留实例归属；恢复环境后继续使用原标识。
- 新建菜单只列出已启用且接入就绪的实例。请求携带实例 ID，后端使用服务器配置或检测结果解析，不接受客户端提供发行版、用户或可执行文件路径。已有会话拒绝改投其他实例。
- Claude 的只读发现进程与扫描间隔按配置隔离，模型缓存按类型实例隔离；相同实例的新建、不同项目和历史会话共用模型目录。相同原生 UUID 在不同环境中登记为不同网页会话。侧栏仅发现并合并请求中启用的 Claude 实例。
- 新建草稿、失败输入恢复及记住的模型按实例隔离。旧默认 Claude 草稿先写入实例存储键，再删除旧键，目标实例已有草稿优先保留。
- 旧客户端仍可使用 `includeClaude: true`，其范围仅为原默认 Claude 实例。

## 接入范围与连接方式

| 类型和环境 | 本轮状态 | 连接方式 |
| --- | --- | --- |
| Codex · 本机 | 可用 | 保留当前 CDP / 服务模式设置 |
| Claude · 各已检测 WSL 用户 | 可用 | 各实例自己的原生 CLI 连接 |
| Claude · 本机 | 当前暂停检测和展示；已保存偏好保留 | 执行适配器尚未提供 |
| Codex · 各 WSL 用户 | 独立检测和开关；执行适配器尚未提供 | 设置明确提示未接通 |

实例描述“哪套程序和运行环境”，连接方式描述“如何访问该实例”。未来新增类型在注册表声明检测和展示信息，再提供执行适配器；未实现适配器的类型不能自动退回 Codex。后续增加更多 Codex 执行实例时，可将运行模式偏好扩展为每个实例一份，只展示该实例支持的连接方式。本轮保留本机 Codex 已有模式与自动恢复逻辑。

## 修正：所有发行版按相同规则接入

此前把当前会话中的测试约定误实现成了按发行版名称限制产品能力的代码，该处理已撤销。产品不再包含“仅识别”的实例字段、状态或入口过滤，也不按某个环境名称拒绝会话及指令操作。

`claude-us` 与其他 WSL 实例一样，根据安装检测结果和适配器能力报告接入状态，按用户自己的实例开关进入列表、新建和指令环境选项；名称、用户、路径及设备权限仍使用通用校验。

本次验证使用 Windows 本机内存配置、模拟页面数据及既有回归用例，没有连接用户正在使用的发行版执行测试。这是本次工作的验证范围，不构成项目对任何特定发行版的永久规则。
