## 修复内容

- 正常切换会话、退出工具页面等操作主动取消旧请求时，不再把该线路标为不可用。请求期限使用 `TimeoutError` 区分，真实超时、网络错误和响应读取失败仍执行原有不可用处理。
- 连接轮询只等待会话状态，不再等待侧栏读取。侧栏继续沿用原有请求合并及后台优先级；停止轮询、隐藏页面、切换设备和替换事件流的代次检查保留。
- 异步问答、跳过问答、原生询问和审批在明确 `notSubmitted=true` 且结果并非未知时释放本次回复锁定，保留答案草稿，允许手工重试。真正结果未知的请求继续保留锁定，不自动重发；迟到失败不得删除更新的回执。

## 问答双线路的版本限制

公开旧 APK `0.0.3 / versionCode=5` 的原生跨源规则只允许 `send/create/setGoal`。问答及权限、表单回复使用 `/api/action/answer`，命令及文件审批使用 `/api/action/approve`；旧规则不能由网页热更新改写。

当前源码的 Android 原生规则和电脑端服务已经支持全部会话动作，并通过 `requestRoutingVersion=2` 协商能力。此次正式 APK 将这些原生改动实际编译入包。新包保留 Bearer、幂等键、服务身份、动作白名单、只读及审批权限检查，不通过其他地址伪装问答动作。

旧 APK 仍受其原生限制；安装本次 APK 后才具备对应能力。此次仅本地编译，不增加版本号、不创建标签、不发布 GitHub Release，也未操作手机安装。
