## 当前约定

用户已撤回跨重启持久保留的要求。远程会话直接共用 Codex 原生侧边会话的创建方式、标签和生命周期；不建立独立持久登记，不通过改写桌面左栏实现隐藏。对于桌面尚未加载的主会话，用户已允许通过原生导航打开后再创建侧边会话。

## 实现

- 侧边创建调用安装版 Codex 的原生侧边入口，使用原生侧边页面组件、标题、权限和上下文边界。当前本机原生入口创建 `ephemeral:true` 会话。
- 从原生 `ThreadScope`、`RouteScope` 的右侧和底部标签读取列表，核对原生内存中的父会话关系。桌面创建、标题变化、远程创建及两端关闭使用同一份状态。
- 临时会话不支持 `thread/turns/list`。正文改为读取原生内存消息，按轮次 ID 和消息 ID 分页，保留图文、工具内容、消息时间及编辑信息；没有复制主会话历史或另外建立历史边界记录。
- 远程关闭前提示不可恢复，再调用原生标签关闭的确认后流程；原生 `onClose` 负责停止、丢弃会话和清理关系。已提交后的超时、连接更换和异常保持未知结果，不自动重复关闭。
- 桌面关闭标签时，远程清理对应列表和缓存；正在查看该侧边会话时返回主会话。重新连接后读取已失效的临时会话返回 404，不尝试恢复或持久化它。
- 菜单和聊天记录仍在内存中复用；侧边列表、正文和侧栏未读标记不写入持久只读缓存。主会话及子代理的已有缓存继续使用。
- 已删除上轮新增的桌面目录过滤组件，并撤回桌面扫描入口、Rust 资源拼接及旧持久侧边登记的读取和写入。原生桥版本为 `57`。

此前创建的持久分支没有自动删除；旧登记字段保留但已无运行代码读取。当前页面中旧方案留下的 4 个持久会话内存侧边标记已恢复，桌面目录过滤组件已卸载。
