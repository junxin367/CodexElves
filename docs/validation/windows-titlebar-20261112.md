# 独立 Windows 客户端标题栏（2026-11-12）

最终要求为最上方标题栏固定 **36 个逻辑像素**，随 Windows DPI 缩放；保持此前移除“连接”“窗口”菜单栏的决定。

标题栏和远程内容使用独立 WebView。原生窗口按照同一物理像素边界分配上下区域，缩放、最大化及 DPI 变化时重新布局，避免远程页面覆盖标题栏。窗口拖动、最小化、最大化／还原与关闭到托盘均保留。

标题栏背景、文字和底部分隔线同步当前页面实际使用的外观颜色，支持自动明暗模式、主题及自定义颜色。连接页和远程页面都使用这一同步方式。连续取色操作串行发送并合并最新颜色，带版本的快照避免启动读取覆盖较新的实时配色。

窗口控制仅授权本地标题栏，连接设置仅授权内置连接页。远程内容只额外获得配色同步能力，原生再次核对当前配置的服务来源，并只接受三组 RGB 字节和布尔模式值。
