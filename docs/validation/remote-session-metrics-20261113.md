# 会话编辑框底栏统计

日期：2026-11-13。

## 展示与口径

- 编辑框外侧左下方显示 `48tk/s  本轮 20步 1m 总 5m`，步数在 Token 用量之前；右侧保留 Claude 订阅额度。
- `m` 为百万 Token，`k` 为千 Token。本轮用量为当前用户轮次的输入、输出合计；步数为模型调用次数，工具调用及子代理汇总不作为主会话的一步。
- “总”为当前原生会话累计 Token。Claude 缓存读取、缓存写入计入输入，原生 `iterations` 存在时采用各次请求记录，避免再叠加顶层用量。
- 速度为本轮输出 Token ÷ 原生执行时长的平均值，包含思考、工具与等待；悬停提示说明这一口径，不以字符数估算 Token。
- 没有实测数据时隐藏底栏统计，单项缺失时不显示该项，真实零值保留为零。新轮次开始后，尚未收到有效本轮统计时继续显示上一轮快照；空统计、仅有累计值或读取失败均不清空已有内容，收到本轮速度、步数或 Token 实测值后再更新。快照保留原轮次身份，悬停提示说明等待期间展示的是上一轮数据。
- 数字变化时最低位先滚动，增加向上、减少向下；大跳变限制滚动圈数和时长，`k/m` 单位切换采用整体过渡。首次显示直接呈现真实值；系统开启减少动态效果时直接更新。切换会话或新值到达会取消旧动画，动画不改变统计数据和底行布局。
- 统计与额度均沿用默认 11px 字号、已有 20px 底行，不增高输入框或移动工具栏。额度圆点两侧为 5px，“已用”前缀保留原有 10px 间距。

## 数据读取与执行隔离

- 统计通过独立只读接口 `/api/read/sessionMetrics` 获取，执行中每 2 秒、空闲每 15 秒后台更新。发送和停止不等待统计。
- Codex 通过数据库中的精确会话 ID 定位当前原生日志。首次最多尾读 8 MiB，之后按文件追加增量解析；重复 `token_count` 和限额通知不增加步数。不扫描子代理或整个归档。
- Codex 尾部缺少当前轮次开始记录时，该轮数据保持未知，会话累计仍可使用原生累计值；不将部分历史误报为完整轮次。
- Claude 使用同一会话已有的原生请求记录，按请求身份去重。旧共享存档只在统计接口中按需补读当前原生日志，不取得发送锁、不执行 Claude 模型、不发布正文更新或改变未读状态。
- 切换会话、实例、设备授权或运行模式后丢弃迟到结果；离页、隐藏或离线时取消读取。旧服务未声明能力时不调用新接口。
