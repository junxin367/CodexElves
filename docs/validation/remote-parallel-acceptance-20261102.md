4. `remote-acceptance-current-20261102.md` 的 R1-17、R1-32 和初始五项优先清单包含较早截点描述。读到 R1-17 时，须采用后续命令 accept/cancel 报告并排除新增文件审批展示；读到 R1-32 时，须采用后续删除预览取消报告作为已完成子场景；读到五项清单 R1-30 时，须采用 E31/E34 已证的正常子场景。以上均不减少仍缺分支，也不更改主表。
