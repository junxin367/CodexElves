# 远程会话与 Android 边界复查

2026-10-18。源码修复与本轮定向验证：**PASS**；部分临时文件清理被自动审批拒绝。本轮复查当前未提交的远程会话、压缩排队与 Android 通知、图片、连接和更新改动；保留此前工作区内容，未重新执行全部历史验收。

## 新增修复

1. **图片未读完时快捷发送漏图。** 发送按钮原已禁用，但 Ctrl/Cmd+Enter 直接调用发送函数。生产函数复现显示普通发送、压缩排队和新建会话会先发送文字，成功清稿又使在读图片失效。发送入口现统一等待图片读取完成，目标提交也受同一保护。
2. **迟到回执清掉新在读图片。** 新图片完成读取前尚未进入附件快照，旧回执会误判当前草稿未变。现有新图片在读时，不清当前输入，也不删除其已保存草稿；没有新编辑时原确认清稿行为保留。
3. **通知写盘阻塞页面生命周期。** 原通知设置及权限标志提交持有页面锁，切换或销毁页面可能等待慢盘。写盘现只持有串行写锁，页面与身份在提交前和发布确认值时用短锁核验；失效写入回滚，不向旧页面推送成功。
4. **Android 渲染进程退出后保留失效页面。** 当前页面退出时立即使旧任务和桥接绑定失效、取消选图、移除并销毁 WebView，显示手动重试入口。保留授权及 Cookie；重试复用已有资源选择与未确认试用版本回退，不自动循环重载。旧 View 的迟到退出回调仅处理该 View。
5. **登录密钥进入 View 状态保存。** 固定 ID 的密钥 EditText 原会参与系统 View 状态保存；现明确关闭该输入框的状态保存，登录成功清空输入的既有行为保留。
6. **旧图片读取锁住新会话。** 切换会话会使旧读取失效，但原全局读取标志仍阻止新会话发送或添加图片。现切换即解除旧读取状态，旧任务完成也不能清除新任务的读取锁或污染提示。
7. **普通发送的身份及压缩交界。** 原空闲发送快路会另生成消息 ID，且内部恢复期间开始压缩时仍可能直接引导活动轮。现复用原生协调器与稳定 ID，空闲正常发送，期间开始压缩或出现旧队列则按原生顺序处理；不支持排队的特殊会话在提交前复核空闲状态。
8. **原生排队确认过早。** 某些本地 queued 返回实际上仍是 pending。现只在原生已排队或已接受的证据成立时返回成功，否则保留未知结果并只查询，不重复提交。
9. **准备期间连接或会话失效仍提交。** 旧准备过程可能借新连接提交，或在已知会话删除后继续加入队列。现绑定原始 manager，并在准备和真正提交前复核实例与删除状态；已开始提交的结果仍按未知回执处理。

原生适配器 guard/export 已同步至 46，产品及 Android 显示版本未修改。通知页面未发现新的样式边界问题。
