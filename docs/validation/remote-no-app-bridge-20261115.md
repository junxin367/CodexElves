# 远程会话移除 Codex App 桥接

日期：2026-11-15。范围为源码、定向回归与构建约束，不代表正式服务已部署或安装后实机验收。

## 清理范围

- 删除 Codex App owner/follower IPC、桌面快照订阅与观察路由。
- 发送、引导、停止、压缩、编辑、审批问答、历史和子智能体读取统一使用独立 app-server。
- 项目、排序、置顶及新建默认值不再读取 App 私有项目映射、账号偏好或内存状态。
- 删除桌面注入中遗留的远程 Fast 查询、设置、新建草稿和提示词优化入口；桌面本地增强继续保留。
- 删除旧适配器测试夹具、桥接验收记录与失效引用，更新 README、移动端指南和服务文档。
- `AGENTS.md` 明确禁止恢复桥接；构建输入检查拒绝旧入口和私有偏好读取，后台协议升至 7。

## 既有检查失败

- 前端全量 492 项中 489 项通过；3 项 Fast 缓存和身份时序失败在修改前的独立快照上同样存在。
- Rust 扩展检查 64 项中 58 项通过、5 项忽略；预热取消测试在修改前的快照上同样失败。
- 全仓格式检查仍指出未修改的 `tool_runtime.rs` 一处格式差异；本次修改的 Rust 文件单独检查通过。

## 功能边界

独立引擎仍遵守原生 writer 锁。其他进程持有的会话可能拒绝发送或删除；本次没有绕过锁、终止持有者或恢复桌面代执行，也不把明确报错当作占用问题已经解决。App 私有待审批请求、内存快照及临时侧边不再提供远程同步；外部持久历史仅通过独立引擎读取。

Windows/Android 壳层与各自网页的通信、Claude 所属实例的原生 CLI 连接、本地协议转换及桌面本地增强不属于远程接入 Codex App 的桥接，继续保留。
