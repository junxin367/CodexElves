管理器和手机页面使用隔离演示数据；Codex 展示页只读复制控件，不修改原窗口、配置或会话。截图未发送真实模型请求或会话操作，也未连接远程公网。模型名、用量、速率、文件路径和会话正文均为示例，不作为性能或端到端验收证据，也不是 Android 真机录屏。

API Key 使用密码输入框遮挡；截图中的 `demo-zrok-token`、`your-name`、`demo-web`、`api.vendor.example`、`C:\Users\demo` 和 `192.0.2.10` 均为演示值，没有采集真实账号、密钥、个人路径或私人会话。

Codex 截图中的 Open in 菜单和提示词设置用于展示控件，不会在演示页实际启动应用、调用模型或提交任务。没有使用 AI 生成软件界面，也没有把演示用量或会话描述为真实工具执行结果。

后续更新素材时，应重新使用演示数据采集，并逐张检查静态图片和 GIF 各帧；如必须使用真实环境，公开前需遮挡密钥、账号、私人域名、路径和会话内容。不要为更换截图删除仍被其他文档引用的历史素材。
