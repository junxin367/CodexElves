# 远程会话

## 功能范围

管理工具新增独立的「远程会话」导航入口。网页服务由 Rust launcher 托管，网页资源嵌入程序，不要求用户另行安装 Node.js 或 Bun。

网页使用已运行 Codex 桌面应用的原生会话管理器，不启动另一套 app-server，不复制执行会话：

- 读取本机项目、会话、完整分页历史和实时事件。
- 在现有项目中新建原生会话，继续已有会话。
- 项目置顶写回 `pinned-project-ids`；会话置顶使用当前桌面的 `pinnedThreads` 服务，不使用已被桌面忽略的旧置顶列表。
- 项目顺序读取 `project-order`；会话排序使用原生更新时间、`sidebar-project-thread-orders`、`codex-sidebar-chat-order-v1` 和桌面排序偏好。网页不保存独立的项目顺序。
- 渲染用户消息、Markdown、代码块、表格、思考记录、命令输出和文件修改；工具记录可折叠。
- 默认继承会话模型和思考深度；明确选择时才覆盖。新的 GPT 思考深度选择不超过 `xhigh`，Claude 不超过 `max`，不批量改写已有会话配置。
- 通过原生发送流程处理桌面当前的消息队列策略，不维护第二套执行队列。
- 处理命令、文件修改、权限审批及常见用户询问。无法安全适配的请求会提示在桌面处理。
- 停止同时调用原生停止与该会话的后台终端清理，不结束其他会话或整台机器的进程。

这不是桌面的完整复制：不提供任意文件浏览、任意 RPC、CDP、脚本执行入口或桌面外部登录代办。图片附件、复杂嵌入式应用和未适配的询问仍需在桌面查看或处理。

## 网页输入与外观

### 模型与上下文

输入框下方同时显示当前模型名称和思考深度；点击后弹出菜单，不再使用两个常驻下拉框。模型名称优先使用原生显示名称，思考深度只列出该模型支持的选项。默认继承会话设置，显式选择仅随下一条消息提交；选择模型时先采用该模型有效的默认深度。菜单支持方向键、Home、End 和 Escape。

模型名称左侧显示 `已用250k / 53%，共475k`，百分比使用独立徽标。数据取自 Codex 原生 `latestTokenUsageInfo` 的 `last.totalTokens` 和 `modelContextWindow`，表示最后一次请求的上下文占用，不是累计 Token，也不按消息字数估算。Token 通知实时更新当前会话；原生未提供有效容量或用量时显示「上下文信息尚未提供」。

并发刷新只接纳当前会话最近发起的有效读取响应。读取期间收到的 Token 通知不会被该读取的旧快照覆盖；首次读取尚未完成时也会暂存通知。用量降低同样生效，不按数值大小判断新旧。菜单随窗口和视觉视口尺寸变化重新限制高度；尚未选定会话或进入新建流程时，输入框保持禁用。

### 选择 Skill

在输入框词首或空白后输入 `/`，按名称、显示名或描述检索当前会话项目中的可用 Skill。方向键切换，Enter 或 Tab 选择；选中后显示可移除标签，空正文时 Backspace 可删除最后一个标签。普通 URL 和完整文件路径不会触发菜单，中文输入法组词时不拦截按键。正文和所选 Skill 分别保留在当前页面的会话草稿中，切换会话后恢复。

新会话按照所选本机项目读取 Skill，不接受网页传入任意目录。发送时同时提交 `$skill-name` 文本标记和原生 `{ type: "skill", name, path }` 输入项，继续通过桌面原有发送队列或创建流程执行。每次发送前重新检查该项目的 Skill 名称、路径及启用状态；已停用、跨项目或任意路径不允许提交。一次最多选择 16 项，发送期间编辑的新草稿不会被旧回执清空。

连续输入会复用同一范围的在途 Skill 查询；光标移出 slash 单词、失去焦点或进入中文组词时关闭菜单，组词结束后才检索。迟到响应不会重新打开已关闭的菜单，旧会话或旧项目的响应也不覆盖新范围。

新建草稿按项目分别保存正文和 Skill，切换项目时恢复对应草稿。项目切换使旧创建请求失去当前页面的操作权，但不取消已经提交的创建任务。成功或部分创建失败后，仍处于原创建页面时将未提交草稿移入新会话；途中编辑不会被原始正文覆盖。切到其它项目后，旧回执不会切换当前页面。回执仍保存完整提交参数，不再重复保存未使用的草稿副本。

### 网页外观

登录页的「网页外观设置」和会话侧边栏底部的「设置」均可选择浅色或深色，调整强调色、背景色、前景色及 10–20px 字号，支持恢复默认。旧版超出该范围的整数值会收敛到最近边界，例如 24px 变为 20px。浅色、深色分别保存颜色，字号统一；消息、侧边栏、菜单及设置文本同步缩放。手机输入框至少使用 16px，以减少浏览器自动放大。

设置即时生效，仅保存在当前浏览器的 `codex-elves-web-appearance` 中，不修改本机 Codex 主题，也不存访问密钥。损坏设置或非法颜色回退到默认值；浏览器拒绝保存时会明确提示。原「电脑需保持开机，CodexElves 与 Codex 桌面需保持运行」提示已从网页移除，实际运行前提仍适用。

### 下拉组件与侧边栏菜单

分组、会话排序、置顶排序、新会话项目和网页主题使用统一的自定义下拉，不调用浏览器原生 `select` 菜单。方向键、Home/End 切换选项，Enter 选择，Escape 收起并返回触发器，点击外部或 Tab 离开会收起；新会话项目可按名称或路径搜索，方便区分同名项目。浮层根据可用空间向上或向下展开，限制高度并内部滚动，不被侧边栏或外观弹窗裁剪。

会话行的「更多」菜单提供打开、置顶或取消置顶；项目行提供在此项目新建会话、置顶或取消置顶。已置顶对象保留标记；桌面端的更多按钮在悬停或键盘聚焦时显示，手机端直接显示。侧边栏刷新保留滚动位置及正在操作的菜单，触发器滚出可见区域时关闭菜单。项目、会话及置顶区仍按原生返回顺序展示，不另外排序。

设置固定在侧边栏底部左侧，「退出」在同一行右侧，不再占用会话头部。「退出」仍撤销当前设备授权，确认步骤和安全行为不变。退出、会话级审批、人工解除发送锁定使用统一的网页确认弹窗，支持键盘取消；全局操作结果从页面顶部居中提示。只读、连接中断和侧边栏设置保存期间禁止相应写操作，保存失败恢复原生已确认的选择。自动恢复会话不收起用户已打开的手机侧边栏，手动选择会话仍收起。减少动态效果的系统偏好会关闭非必要动画。

模型菜单贴近模型按钮展开，间距为 4px，空间不足时向下翻转或避让边缘；不再对齐整个输入框的左上方。模型列表与推理等级分别滚动，模型数超过 8 个时显示搜索，可按显示名和请求标识查询。选择后保留滚动位置和可见焦点，中文组词期间不重建搜索输入。鼠标或触屏点击控件不显示高亮外框，键盘 Tab 导航仍保留焦点提示。上下文百分比以普通文字显示；发送按钮使用居中的 SVG 上箭头，正文和 Skill 均为空时禁用，发送中继续阻止重复提交。

## 启用与连接

1. 使用包含本功能的新版本 CodexElves launcher 启动 Codex。旧的、仍在运行的 launcher 不会自动获得新服务。
2. 打开管理工具的「远程会话」页面，先设置访问密钥。同一行左侧「生成」只将随机密钥填入输入框，也可手动输入 32–256 个非空格 ASCII 字符；右侧「保存」才使密钥生效。生成草稿不撤销已授权设备。请复制并妥善保管，离开页面后无法恢复明文。
3. 打开「远程会话网页」栏目右上角开关，点击「保存并应用」。后台已连接时立即启停；若启动时所有增强和模型代理都关闭、尚无后台，首次保存后需重启 launcher。启用后不要求开启其他增强或模型代理。
4. 确认「网页服务运行中」与「Codex 原生会话已连接」。
5. 在手机打开访问地址，网页只显示访问密钥输入框和连接按钮。输入长期访问密钥后进入会话，不再填写设备名称或生成一次性配对码。
6. 不再使用某台设备时，点击设备旁的「撤销」，或在网页点击「退出」。

电脑必须保持开机，CodexElves launcher 和 Codex 桌面应用必须保持运行。此功能不负责唤醒电脑或设置 Windows 开机任务。

### 网络配置

默认配置为**关闭**，监听 `127.0.0.1:45222`，仅可从本机访问。它不占用模型代理的默认端口 `45221`，也不扩大现有局域网代理的会话管理权限。

手机连接有三种配置方式：

- **Cloudflare Named Tunnel（固定域名）**：使用已有账号、自有域名和 remotely-managed 隧道。管理器启动 cloudflared 并复用同一个隧道，不创建 Quick Tunnel 或临时域名。
- **直接 HTTPS**：设置可访问的本机 IP 或 `0.0.0.0`，同时填写 PEM 格式的证书和私钥路径。证书需匹配访问地址，并被手机信任。
- **现有 HTTPS 反向代理**：保留本机监听，将你已配置的 HTTPS 入口转发到此独立端口，并填写「HTTPS 外部访问地址」。代理需保留正确的 Host 和 Origin，允许 SSE 长连接，不能缓存或缓冲实时事件。

外部访问地址只能是 HTTPS 网站根地址，不能包含凭据、子路径、查询参数或 fragment。非本机监听缺少证书时会被拒绝；不会配置路由器端口映射或修改防火墙规则。

配置 HTTPS 外部入口后，请通过该 HTTPS 地址登录。密钥不会写入连接链接。

### 固定域名的 Cloudflare 配置

1. 没有 Cloudflare 账号时，点击管理页「注册 Cloudflare」自行完成注册，再将自有域名接入 Cloudflare。通过「打开 Cloudflare 控制台」进入 Networking → Tunnels，创建 **remotely-managed Named Tunnel**，不要创建 Quick Tunnel；「固定域名配置指南」链接到官方步骤。
2. 为该隧道配置 Published application / Public hostname，例如 `codex.example.com`，Service 填 `http://127.0.0.1:45222`。若修改管理器监听 IP 或端口，必须同步修改此 Service；IPv6 回环使用 `http://[::1]:45222`。
3. 保留原始 Host，不设置 HTTP Host Header 覆盖。固定域名需正确路由到同一隧道；仅连接 Cloudflare 网络并不能证明 DNS 和 Service 已配置正确。
4. CodexElves 在首次启用时自动下载官方 cloudflared，也可提前点击「下载官方程序」。无需管理员权限、手动安装、设置 PATH 或安装 Windows 系统服务。保留默认程序设置，已有自定义程序则通过折叠的高级设置填写路径并检查版本。
5. 从 Cloudflare 的连接器安装命令中**只复制隧道令牌**，在管理器保存；不要复制整条命令。填写固定访问地址，例如 `https://codex.example.com`。
6. 管理器使用本机回环 HTTP 监听，不填写本机证书和私钥；公网 TLS 由 Cloudflare 处理。
7. 设置并保存网页访问密钥，打开远程网页及 Cloudflare 栏目右上角开关，点击「保存并应用」。连接状态以 cloudflared 的本机 `/ready` 结果为准，不把“进程已启动”当作“已连接”。
8. 从手机打开固定地址并输入访问密钥。固定域名不会随电脑、launcher 或 cloudflared 重启改变；只有人为修改隧道或 DNS 绑定才会影响地址。

隧道随网页服务启停。关闭隧道管理只停止 CodexElves 自己启动的 cloudflared，不停止其它隧道、系统服务或本机 Codex。cloudflared 负责网络断线重连；进程退出后 30 秒重试，重新保存应用可立即重试。

自动下载从 Cloudflare 官方 GitHub 发布页取得版本及 SHA-256，下载同一版本的 Windows x64 / x86 可执行文件，校验通过并检查版本后才使用。程序保存在 CodexElves 状态目录的 `tools/cloudflared/`，不修改系统 PATH 或覆盖已有 cloudflared；启动时复核校验值，已下载程序可离线复用，不自动升级正在使用的程序。首次下载失败时显示可重试的错误，本机网页保留；通过配置直接启用时，下载在后台进行，不阻塞本机网页的状态和停止操作。其它平台可使用自定义官方程序路径。

隧道令牌和网页登录密钥是两种不同凭据：前者连接 Cloudflare，后者授权访问本机 Codex。Windows 使用当前用户的 DPAPI 加密保存隧道令牌；其它系统将令牌保存在仅当前用户可访问的目录。隧道令牌通过子进程环境变量传递，不写入进程命令行或日志，也不返回手机网页。

现有 SSE 实时通道保留。Named Tunnel 不依赖 Quick Tunnel；此功能不接入 HAPI 的公共中继，也不引入另一套执行会话。

## 设置与安全

| 设置 | 行为 |
| --- | --- |
| 启用远程会话网页 | 默认关闭，保存后启停 |
| 监听 IP、独立端口 | 端口范围 1–65535；端口占用会显示错误，不影响模型代理 |
| 固定 HTTPS 访问地址 | 已绑定的 Named Tunnel 域名，或已有 HTTPS 入口 |
| Cloudflare 隧道管理 | 默认关闭，使用固定隧道，随远程网页启停 |
| Cloudflare 程序 | 首次自动下载并校验，已下载程序离线复用；高级设置可覆盖程序路径 |
| Cloudflare 隧道令牌 | 仅本机保存，独立于网页访问密钥，不写入命令行 |
| 访问密钥 | 长期有效，生成与保存独立，使用同一个输入框；保存替换后旧设备授权失效 |
| HTTPS 证书、私钥路径 | 必须同时配置；私钥仅在本机读取，不发给网页 |
| 设备授权有效期 | 1–720 小时，默认 168 小时，仅对新登录设备生效 |
| 允许远程审批及回答询问 | 关闭后需在桌面处理，后端同样拒绝这些操作 |

访问密钥使用加盐 PBKDF2-HMAC-SHA256（600,000 次）保存，不保存明文；密钥验证有来源限速及并发上限。网页登录后使用随机设备令牌，保存在 HttpOnly、SameSite=Strict cookie 中，HTTPS 连接要求 Secure；磁盘仅保存设备令牌哈希。网页不将访问密钥写入 URL、localStorage 或 sessionStorage。请勿向不可信的人透露密钥。

密钥在隧道和网页服务重启后继续有效，设备授权则遵守有效期。更换密钥使所有旧 cookie 失效，包括服务重启后从磁盘恢复的旧设备；不取消已经提交到 Codex 的任务。撤销单台设备会使其当前授权失效，但知道长期密钥的人仍可再次登录；要阻止再次登录，必须同时更换密钥。

有交互和审批权限的设备可以通过 Codex 操作本机项目，应当像对待桌面账号一样保护它。撤销和到期会停止该设备的数据流，并拒绝后续操作。

服务检查 Host、Origin 和跨站请求，Markdown 不执行 HTML 或 `javascript:` 链接。审批使用原始 request ID（包括数值 `0`），核对所属会话和请求类型；已结束请求不会继续放行。

命令审批只展示和提交原生请求允许的决定；网络审批显示协议、目标主机和端口。询问答案只接受文本，MCP 外部登录等 URL 询问不能通过远程 API 回答，需回到桌面处理。

访问密钥哈希、授权设备及消息回执保存在 CodexElves 状态目录下的 `remote-access-key.json`、`remote-access-devices.json` 和 `remote-access-receipts.json`。Cloudflare 令牌保存在 `remote-access-secrets/cloudflare-tunnel.json`。损坏的授权文件会使远程服务拒绝启动，但不会使原有模型代理启动失败。

管理器已移除只读访问选项；旧配置中的 `readOnly=true` 仍遵守原有权限，不因 UI 调整自动扩大已有设备权限。密钥栏目不再列出本机地址；固定公网地址在 Cloudflare 栏目中设置及复制。供应商启用开关和远程栏目使用与 Checkpoint 概览一致的开关样式，供应商原保存与启停逻辑不变。

## 断线与消息回执

消息提交前保存客户端请求 ID 与回执。同一设备重复提交相同 ID 和内容不会重复发送；同一 ID 携带不同内容会被拒绝。

回执的「完成」指提交动作完成，不代表模型已经生成完毕。网页断线不会终止桌面任务，重新连接后从原生历史恢复。

若发送回执丢失、原生客户端报告结果未知，或服务在提交中重启，网页会锁定重复发送并查询回执。它不会自动重发。请先检查会话，再通过「已人工确认」解除锁定；不要仅因为没有看到回复就再次提交。

已登录设备在桌面暂时离线时保持自动重连，不退回密钥输入页。损坏或属于旧设备授权的浏览器回执会锁定发送并提示人工核对，不会因解析失败白屏，也不会自动丢弃记录后重发。迟到的旧回执和旧授权请求不能解除新消息的锁定或恢复已经退出的页面状态。
