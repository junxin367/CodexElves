# CodexElves 产品规范

本文记录已确认的产品行为与交互约定，适用于本项目自行实现的管理器、Codex 注入增强、远程网页、Windows 独立远程客户端及 Android 界面。具体控件已有明确特殊规则时，按对应例外执行。

新增或调整产品约定时，维护对应章节，并同步核对实现处的需求注释和相关使用说明。

## 远程项目视图

项目目录合并独立 app-server 的已保存项目与同一 Codex Home 中 Codex App 添加的本地项目。按明确项目 ID、同一 Home 的迁移映射或唯一匹配的完整根目录集合去重；同名、共享部分目录的项目分别保留，不从历史会话工作目录生成项目。

Codex 实例已启用且命中当前筛选时，全部 Codex 项目均可见，包括空项目、App 新增项目和置顶项目。筛选只限制项目下的会话，不得因缺少匹配会话而隐藏 Codex 项目。只筛选 Claude 时，共享项目按匹配的 Claude 会话显示；关闭的实例不因项目可见而被启用。

远程项目继承 Codex App 的项目置顶及置顶区、普通项目区的排列顺序，App 后续修改在侧栏刷新时生效。远程明确置顶或取消置顶仅保存在远程服务中，对操作时的 App 排序记录有效；App 后续改变置顶或顺序后，旧远程覆盖失效。仅存在于原生引擎的项目继续使用远程偏好，并按原生顺序补在对应分组后方。

项目同步只读持久化的项目定义、项目 ID 映射、项目顺序和置顶列表，不读取账号、执行队列、审批或 App 内存状态，不连接或驱动 Codex App，也不修改 App 的状态文件。App 尚未迁入原生引擎的项目可以查看文件和选择新建；只有用户明确发送新会话时，才通过独立 app-server 的幂等项目导入接口登记项目。读取失败保留同一 Home 上次成功的项目记录并显示原因，不影响原生项目列表。

## 交互体验规范

### PC 会话列表菜单按钮

PC 网页和 Windows 独立远程客户端在宽于 760px、支持 hover 且使用精细指针时，最近、置顶和项目下会话行的“…”按钮仅在悬停对应行时显示；选中会话或标题获得焦点不使按钮常显。键盘聚焦菜单按钮以及该菜单展开期间保留入口，执行/未读图标与按钮互斥显示。未显示的按钮不接受鼠标点击，保留原有布局和键盘可达性。手机及触屏沿用现有按钮显示与长按菜单规则。

### 会话编辑区斜杠命令

Codex 和 Claude 会话编辑区的 `/` 菜单均提供“提示词优化”入口，支持按“提示词优化”“优化提示词”、`prompt-optimize`、`optimize` 的连续片段筛选。入口与工具栏优化按钮共用可用状态，不依赖 Claude 原生压缩或目标能力；只读、输入禁用、执行中、停止中或等待回执时保持不可选。鼠标点击及 Enter/Tab 键盘选择均只移除当前 `/` 查询文本，保留其余提示词、Skill 和附件，然后调用现有独立提示词优化流程，不直接发送消息。

### 会话权限菜单

Codex 和 Claude 的会话权限入口只显示权限图标和当前模式，不显示右侧下拉箭头；点击仍打开原权限菜单，其他 Select 控件的箭头保持不变。权限菜单的标题、选项、说明及链接文字统一继承当前设置的 `--font-size`，不再使用独立固定字号。Codex 的“了解更多”紧随“应如何批准 Codex 操作？”显示，底部不再重复出现。Claude 不显示“模式”标题，权限说明及待生效原因均位于选项列表顶部，底部不重复显示；其他 Select 弹层继续沿用原定位。

Claude 仅在存在对应的权限切换记录、该记录仍处于等待状态且原生权限尚未达到目标模式时显示待生效说明。仅凭选择值与原生值不同不显示；原生权限已经等于目标模式时，即使仍有旧等待记录也不显示。说明分别标明已选择的目标权限和当前原生权限，并保留原生返回的具体等待原因；其他情况只显示常规的“绕过权限”支持说明。

### Windows 任务栏未读角标

Windows 独立远程客户端任务栏角标与会话栏实际显示为未读的主会话数量一致，不按消息或轮次累加。会话处于执行中时不计未读，即使原未读标记仍然保留；执行结束且未读标记仍存在时恢复计数。执行状态与会话行共用判断：`priority.active` 的布尔值优先，缺失时读取 `status` 的 `active / inProgress`，关联侧边执行状态同样排除；等待回复不按未读计数。

最近、置顶和项目中重复出现的主会话只算一次，侧边子会话、子代理及归档会话不单独计数。搜索、折叠和快捷筛选不改变总数，读完后减少，为零时清除，超过 99 仅在图标上显示 `99+`。

### 会话活动耗时

远程会话渲染区的活动摘要从“已处理 1秒”开始计时；已知耗时不足 1 秒（含 0 毫秒）时，统一显示 1 秒，完成后的“用时”摘要沿用同一下限，不显示“<1秒”。该下限仅用于展示，不改写原始耗时；缺少有效时间或等待启动时，保留原有状态提示。

### 会话任务清单恢复

任务清单只来自原生计划，不根据正文或执行时间生成。Codex 按轮次显示；独立服务收到计划更新后保留该会话、该轮次的最新快照，新开页面、刷新及切回会话时通过历史响应补齐，不等待模型再次更新计划。缺少计划字段不代表清空，明确空数组才清空；迟到历史和旧版本计划不能覆盖新更新。编辑回退只撤销被移除轮次的计划，删除会话释放全部计划；侧边清单只来自自身事件，过期后随只读正文保留，关闭后释放。

Codex 快照仅属于当前独立引擎运行代次；服务或引擎重建后，不承诺恢复之前未持久化的计划，也不把旧浏览器缓存当作当前计划。其他客户端的任务若没有被本服务收到，不通过 Codex App 桥接补齐。

Claude 清单属于整个会话，始终显示完整有效历史中的最新快照，并放在正文末尾。首屏和旧页均额外返回该快照，不受每页 10 轮或实时通知轮次窗口影响；明确清空后，后续轮次不得从旧任务种子恢复已删除清单。切换会话或授权时隔离状态，迟到读取不能覆盖更新或回退后的清单。

### 会话 Token 统计 hover

远程会话输入区左下 Token 统计的 hover 使用一行描述，按“首 Token 时间 · 本轮耗时 · 缓存命中率”的顺序，仅显示当前轮次已经取得的原生实测字段。字段尚未返回时整项省略，不显示 `—`；三项均未返回，或新轮次尚未取得统计时，不显示 hover。底栏原有速度、步数和 Token 汇总保持不变。

首 Token 时间从轮次开始计算到首个真实模型流式输出，正文、思考或工具参数均可作为首个输出，工具执行结果不计入；不得用完整回复到达时间代替或估算。缓存命中率为本轮各次模型调用的缓存读取 Token 总量除以输入 Token 总量，任一相关字段缺失时不输出该比例。

右侧侧边会话沿用相同的底栏与 hover，但使用独立的 `codex-side` 统计源，按侧边自己的 `threadId / turnId / responseId` 读取和去重。只累计侧边创建后收到的 `rawResponse/completed` 实测用量，不读取主会话 rollout，也不把继承的主会话上下文或累计 Token 计入侧边“本轮”和“总”。原生 `thread/tokenUsage/updated` 的上下文占用继续用于上下文环，不作为侧边累计 Token 的来源。

侧边过期后保留最后已经取得的统计，主动关闭时随正文释放；切换主会话或其他侧边时取消旧读取，迟到回执不得覆盖当前侧边。原生只读子代理仍不显示该输入区统计。

### Claude 账号邮箱脱敏

Claude 账号信息弹层的眼睛图标紧跟邮箱文本显示，订阅等级仍位于账号行右侧。邮箱默认脱敏，`@` 前只显示前 3 个字符并固定追加 `***`，域名保持完整，例如 `sarahconnor@meiguoup.com` 显示为 `sar***@meiguoup.com`。点击眼睛在当前弹层内切换明文与脱敏，不持久化明文选择；关闭再打开或账号发生变化时恢复脱敏。没有有效邮箱时保持“账号信息”，不显示眼睛。

脱敏同时适用于邮箱文本、悬浮 `title` 和底部额度按钮的读屏标签；只有用户明确点击显示后，当前弹层的邮箱文本及其 `title` 才使用完整邮箱。图标使用现有 `eye / eyeOff`；邮箱按内容宽度布局且允许收缩，过长时省略，不能把紧跟账号的眼睛挤回行尾。

### Claude 额度重置时间 hover

Claude 额度弹层的 5 小时和 7 天窗口右侧继续显示“1 小时后 / 6 天后”等相对时间；两个相对时间均支持 hover，提示完整年月日及 24 小时制时分，不显示秒，并保留目标 WSL 的时区缩写和 IANA 名称。读屏标签使用同一完整时间。目标 WSL 时区未知时只提示时区未知，不退回浏览器或宿主机时区生成精确时间。

### 弹出菜单的水平展开方向

普通按钮菜单、Select、模型菜单等采用通用定位规则的菜单，按**可视区域左侧 65%、右侧 35%**划分展开方向。会话主菜单采用下方主会话区域内的固定间距规则，Open in 保留固定向左展开。

以触发入口的水平中心确定所属区域。使用实际可视区域的左边界和宽度计算，包含缩放、平移产生的偏移：

```text
入口中心 = (入口左边缘 + 入口右边缘) / 2
方向分界 = 可视区域左边界 + 可视区域宽度 × 0.65
```

| 入口中心位置 | 首选展开方向 | 水平对齐 |
| --- | --- | --- |
| 小于方向分界，即左侧 65% 范围内 | 向右展开 | 菜单左边缘对齐入口左边缘 |
| 大于或等于方向分界，即最右侧 35% 范围内 | 向左展开 | 菜单右边缘对齐入口右边缘 |

恰好位于 65% 分界的入口归入右侧 35%。例如，可视区域宽 1000px、左边界为 0 时，中心位于 600px 的入口向右展开，中心位于 650px 或 900px 的入口向左展开。

先按上述分界确定首选对齐，再沿用现有的边缘避让，通用菜单与可视区域边缘至少保留 8px。重新定位时使用最新的入口和可视区域坐标；窗口缩放、可视区域平移或侧栏、面板布局变化不能沿用旧坐标。

本规则只调整水平展开方向。菜单的宽度、高度、上下展开条件、与入口的垂直间隔及滚动行为继续遵循各控件的现有规则。手机会话菜单已有的“宽度取视口 65%”属于尺寸约定，与本条方向分界分别维护。

### 已有特殊定位规则

已有明确固定方向、固定对齐或指定坐标的菜单保留原规则，不因通用分界调整而批量覆盖。

| 现有菜单或浮层 | 保留的规则 |
| --- | --- |
| 远程会话主菜单（PC 网页、Windows 独立远程客户端、手机及 Android） | 显示在主会话区域内，菜单顶部距该区域标题栏底部 20px，右边缘距主会话右边缘 20px，不参与 65% / 35% 方向判定；侧边标签页开关及宽度变化不改变此间距。窗口缩放、分栏拖动、标题栏高度变化时按实际边界动态定位；窄屏缩小菜单宽度、低窗口缩小可滚动高度，不能改回按钮对齐或整窗口右对齐 |
| 右键、长按触发的上下文菜单 | 以实际点击或长按坐标定位，并保留现有边缘避让 |
| 命令 / Skill 输入补全层 | 对齐整个输入框，沿用输入框上方的补全布局 |
| Codex 注入增强及 Windows 独立远程客户端中的 Open in | 固定向左展开，菜单右边缘对齐整个 Open in 按钮组右边缘，不参与 65% / 35% 方向判定；空间不足时仅平移，视口两侧至少保留 8px；远程客户端保留 178px 菜单宽度、6px 垂直间隔及原有上下避让规则，列表刷新、滚动及窗口变化后仍采用同一定位 |
| 管理器中已有固定对齐的选择器、输入补全及日期范围菜单 | 沿用各控件已有的左对齐、右对齐和输入框宽度约定 |
| Claude 额度详情、上下文用量及 hover 提示浮层 | 沿用各自固定对齐、上下避让或居中规则 |

会话列表右键菜单打开期间发生侧栏刷新时，保留同一个弹层节点并将触发入口换绑到同一会话的新行，不重新播放打开动画，也不重复调用 `showPopover`。右键锚点保存为行内偏移，刷新后按新行位置重新计算并继续执行可视区域边缘避让；原会话行已消失或不可操作时关闭菜单，不能重绑到其他会话或沿用旧屏幕坐标。

新增通用菜单默认遵循 65% / 35% 规则。新增明确的特殊定位约定时，在对应实现附近说明适用场景，并在本节记录例外。

### 实现与验收

远程会话的通用水平定位统一使用 `assets/remote-access/ui/position.js` 中的 `menuHorizontalLeft`。Select、普通按钮菜单和模型菜单复用同一计算，避免各自保留旧的 50% 分界。会话主菜单在 `assets/remote-access/session-menu.js` 中读取 `.conversation` 的实际边界及 `.conversation-header` 的底边，以“标题栏底边 + 20px”“主会话右边缘 - 20px - 菜单宽度”定位，并持续跟踪这些边界及可视视口。远程客户端 Open in 在 `assets/remote-access/features/session/open-in.js` 中按“按钮组右边缘减菜单宽度”固定向左定位，并通过通用弹层的 `popupFit` 回调统一处理首次打开、列表刷新和全局重定位。

调整或验收相关菜单时，核对以下场景：

- 入口中心位于可视区域 50%～65% 之间时，向右展开。
- 入口中心位于 65% 分界之前、恰好位于分界及越过分界时，分别采用正确方向。
- 可视区域存在水平偏移，或窗口、侧栏、右侧面板改变布局后，按最新坐标重新判断。
- 左右边缘避让、现有宽高及上下展开规则保持有效，已有特殊定位菜单继续沿用例外。
- 会话主菜单首次打开、侧边标签展开/收起、分隔线拖动、左侧栏开关、窗口缩放及标题栏高度变化后，始终位于主会话区域内，距标题栏底部与右边缘各 20px；即使按钮坐标不变而会话边界变化，也必须更新位置。PC 默认宽 300px，手机短边不足 600px 时默认宽为可视视口的 65%，空间不足时缩小宽度以保留会话两侧各 20px。
- 远程客户端 Open in 的入口位于 65% 分界任一侧时均向左展开；应用列表加载或刷新、页面滚动、窗口缩放及右侧面板变化后，继续右对齐按钮组并保留原有尺寸、上下避让和边缘留白。

### 子会话的侧边标签

PC 网页和 Windows 独立远程客户端从会话菜单的子智能体列表、已完成列表或正文子智能体入口打开子会话时，使用与侧边会话相同的右侧标签面板。主会话选中项、输入草稿、正文及历史导航保持原样；重复打开同一子智能体复用已有标签，不重载独立页面。子智能体保留原生只读限制，不能因进入标签而开放发送、编辑或审批。

子智能体、侧边会话、文件和变更可同时保留标签，按主会话保存选中项、显隐和阅读状态；切换主会话后切回恢复原标签，授权变化清理全部标签。关闭标签只卸载页面。手机和 Android 继续使用原有关联会话整页。

### 删除带侧边会话的主会话

删除 Codex 主会话时，只有全部关联侧边均未处于执行状态才允许继续。任一侧边正在执行时直接拒绝，提示“侧边会话执行中，无法删除”，不得由删除流程自动中断该侧边，也不得派发主会话删除。服务在删除预检及取得各侧边锁后分别核对，避免预检后的新发送绕过限制。

全部侧边空闲后，独立远程服务逐个暂停并清理其待发队列，通过原生 `thread/unsubscribe` 确认侧边关闭，再执行主会话的原生 `thread/delete`，不要求用户先手动关闭空闲侧边。任一侧边关闭失败时不得派发主会话删除，并明确提示主会话未删除；主会话执行中、状态未知、压缩、待处理交互或写入结果待核对等既有保护保持不变。原生只读子智能体仍由主会话删除流程处理，不能当作服务侧边单独退订。确认文案必须说明所属临时侧边将关闭，执行中的主会话或侧边需先停止。

### Open in 的应用识别与前台显示

Windows 独立远程客户端的 Open in 由远程服务所在电脑独立检测和启动应用。支持 VS Code、Visual Studio、IntelliJ IDEA、Sublime Text、GitHub Desktop、File Explorer、Git Bash、Cmder、Rider、PowerShell 和 WSL；只显示当前服务实际检测到的目标，前后端应用 ID 列表同步维护。

IDEA 检查 App Paths、PATH 和常见 JetBrains 安装目录。PowerShell 优先使用 PowerShell 7，缺少时使用系统 Windows PowerShell。PowerShell 和 WSL 在已安装 Windows Terminal 时使用独立窗口，并明确指定所选程序和会话目录；缺少 Windows Terminal 时正常显示启动所选程序。

Git Bash 和 WSL 的主按钮及展开菜单图标从当前服务实际检测到的可执行文件提取，以 PNG 数据返回，不向网页公开安装路径。图片缺失、格式无效或加载失败时沿用原终端图标；其他应用图标和启动方式保持不变。

WSL 项仅对当前实际由 WSL 实例执行、且已取得原生对话恢复信息的会话显示。判断依据是服务端保存的实例身份，目录是 Windows 盘符、`/mnt/` 挂载还是 WSL UNC 不改变实例归属；本机实例不因项目位于 WSL 目录而获得入口。点击后使用同一发行版、用户、Linux 工作目录及 CLI，进入当前已有对话：原生任务仍存在时使用 `attach`，空闲历史使用原生会话 ID `resume`；不另建对话或重复执行当前任务。启动继承该 WSL 用户的登录环境和时区，不借用其他实例。当前 Codex WSL 执行适配器尚未就绪，本机 Codex 会话不展示 WSL 项。

用户点击打开后，应正常显示应用，并恢复、激活所选应用的新窗口或当前目录对应的已有窗口。PowerShell 和 WSL 使用 Windows Terminal 新窗口时只确认本次新窗口，不能用同目录的旧终端代替当前对话；PowerShell 标题显示初始目录，WSL 标题显示对话名及原生会话短 ID，用于区分同目录下的不同对话。只通过 Windows 系统接口处理目标应用，保留独立服务边界，不复用 Codex App 或管理器执行通道。

启动成功与前台显示分别确认：仅在目标窗口实际成为前台时回执 `foreground: true`。窗口尚未出现或 Windows 未允许激活时保留启动成功回执，明确提示用户在任务栏查看，不因激活失败重复启动。不得模拟按键或修改系统前台限制来伪造成功。

### Windows 远程客户端窗口恢复

Windows 独立远程客户端主窗口在启动时恢复关闭前保存的逻辑大小和物理位置，关闭到托盘及退出时继续保存。目标显示器的 DPI 用于换算实际像素尺寸；同屏且原窗口完整可见时，大小和位置逐像素保持不变。

当前显示器无法完整容纳时，只缩小到显示边界并平移必要距离；原位置已离开所有显示器或配置无效时回到屏幕中央。最大化状态和用于还原的普通窗口尺寸分别保留，不能把最大化后的屏幕尺寸覆盖为普通窗口大小。

### Windows 独立客户端编辑区

Windows 独立远程客户端切到后台前若焦点位于会话编辑框，切回前台后恢复该编辑框的焦点和光标选区，可直接继续输入；后台前焦点位于侧边栏、按钮或其他控件时不抢到编辑框。窗口尚未取得前台焦点或编辑框已禁用时不强行恢复。

编辑框内容超过最大高度后，无选区且光标位于文本末尾时，回车换行和输入使滚动位置跟随到底部，保持光标可见；修改中间内容、撤销恢复或载入草稿时不因此强制改变阅读位置。

“+”和提示词优化入口使用正常前景色 `var(--text)`，不再以次要文字色显示；提示词优化使用与 `/` 菜单一致的 `sparkles` 矢量图标，优化完成后的绿色状态保持不变。“+”在悬停、按下、键盘聚焦和菜单展开时使用 `var(--composer-hover,var(--hover))` 背景，与模型按钮的交互一致。

### Claude 会话退出回收与启动补偿

空闲进程回收以退出为主、启动补偿为辅。关闭服务开关、管理器托盘退出、内置重启、launcher 正常结束及安装升级时，先停止新派发和自动重连，再通过同一实例的原生 CLI 停止安全空闲会话，确认完成后结束 Windows 后台。普通网页断开、远程客户端关窗及管理器窗口收进托盘不触发回收。

只处理本服务创建且保存了原生会话及后台任务身份的 Claude 会话。执行、审批、问答、压缩、未发送草稿、后台任务、原生队列或发送／编辑结果待确认时保留会话；无法确认身份或读取状态时也不停止。轮次 `done` 不能代替进程退出证据。

每项回收分别保存已停止、保留原因或结果未知。正常退出后，启动只核对未确认项；缺少旧版记录或上次异常退出时，才补登记尚未完成回收的受管身份。已确认停止的历史会话后来被原生终端恢复，不因服务启动再次回收。后台仍运行时每 15 秒复查待回收项。用户通过远程继续使用某个会话时取消旧请求，停止与发送共用会话锁，迟到回执不得影响新任务。意图保存失败时不停止目标；异常强制结束不报告为回收成功。

整体清理最多等待 55 秒，本机退出接口保留 60 秒处理预算，调用方保留 65 秒响应预算；超时项继续等待启动补偿。安装包使用包内新版退出 helper，旧服务没有接口时保留受管身份供新服务启动核对，不复用任何 Codex App 桥接。

Claude 新建后台会话通过原生会话设置传递当前 WSL 用户的有效时区，避免复用 daemon／预热进程时落回其他系统时区。保留会话不能靠强制重启统一 daemon 来修正时区。
