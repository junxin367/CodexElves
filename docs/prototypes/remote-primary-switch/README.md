# 主链路切换交互原型

本目录为独立审核原型，沿用管理器现有布局与绿色主题。所有 Token、地址状态和测试结果均为演示数据，不调用真实管理器或隧道服务。

最新布局：`zrok / frp` 位于「公网入口」标题右侧；地址名称为「固定公网地址」；不展示证书相关控件。第一行按服务器地址、Token、服务端口、公网映射端口排列，两个端口输入框均为 80px 且隐藏上下箭头。主链路操作结果替换按钮左侧的默认说明，只展示文字，无背景、边框和重复弹窗。

## 打开方式

可以直接打开 `index.html`，也可以在仓库根目录运行：

```powershell
node docs/prototypes/remote-primary-switch/server.mjs
```

浏览器访问 `http://127.0.0.1:1491`。预览服务仅监听本机，仅提供本目录的页面、样式、脚本和图标。

## 审核操作

1. 点击 `zrok / frp` 面包屑，检查表单切换；右上角「当前生效」不随查看操作改变。
2. 在 FRP 表单点击「保存并测试」，查看验证结果；再点击「应用为主链路」，查看切换中和生效状态。
3. 点击 zrok，再应用，可演示切回 zrok。
4. 使用页面顶部「预览场景」，查看缺少 HTTPS 和验证失败时的表现。
5. ngrok 区域始终保留，主入口切换不会清空其输入内容。

顶部深色栏仅为原型审核工具，不属于正式产品界面。
