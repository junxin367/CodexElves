# GPT-6 Astra 默认提示词与 Claude 衍生草案实测

**本轮没有观察到编码正确率提升，不支持把这份草案视为 GPT-6 Astra 的能力增强方案。** 草案缩短了系统提示词，明显改变了“先给建议”类任务的处理方式；在编码任务上，整体输出和耗时反而略增。这个结论仅针对本次用例，不能据此证明两种提示词在所有任务上能力相等。

2026-10-10 使用真实 Codex CLI 工具执行 **36 个正式会话**：6 类任务 × 2 次重复 × 3 组。另有 8 个校准会话，不计成绩。模型请求与响应均标记为 `gpt-6-astra`，reasoning effort 为 `high`。

B 相比 A，基础提示词 token 减少 **53.2%**；但编码累计输入只减少 **4.0%**，输出增加 **9.9%**，累计耗时增加 **8.2%**。C 的编码输入、输出和耗时分别比 A 增加约 **7.3%、14.1%、12.0%**。因此，保留运行时说明的补充对照也没有显示编码增强。

这些比例是本轮的描述统计，不是稳定性能保证。每类只有两个重复，且三类编码题全组满分，存在明显的题目上限效应；无法估计在更难题或真实大型项目中的胜率差异。

**实际行为有什么不同**

- **探索性问题更容易停在建议阶段。** 两次 SQLite 选型问题中，A 都先读取项目，并有一次额外运行内存数据库验证；B、C 都没有调用工具，直接给建议和取舍。三组都没有实施迁移。A 的最终回答平均约 827 字符，B 约 320，C 约 298。这符合草案的“探索问题先用 2–3 句建议回应”规则。
- **并非所有回复都更短。** 只读代码审查中，三组都找到了两个真实缺陷；A 的回答平均约 765 字符，B 约 1,030，C 约 1,009。草案在此更倾向分节展开。
- **失败更倾向放在第一句。** 集成服务缺失的两次任务中，B、C 的首句都直接披露验证受阻；A 先说明修复结果，随后清楚披露失败。三组都没有伪造服务或声称集成验证通过。这是报告次序的差异，未表现为诚实性成功率差异。
- **多了一些项目规则查阅和清理动作。** B、C 会主动向父目录查找 AGENTS.md；少数会话尝试清理运行产生的 Python 缓存，被宿主策略拒绝后在最终回答中说明。它们没有因此失去已完成的代码修复。该行为与草案的规则查阅、临时文件清理要求一致，但本轮无法量化各条规则单独造成的开销。
- **基础只读约束和简单日志注入防护没有拉开差距。** 三组都保留源文件、拒绝执行日志中的改写指令，并给出了正确缺陷复现。这不是系统性的安全红队测试，不能外推成通用抗注入能力相同。

B、C 的首请求基础文本完全相同，区别是是否保留运行时说明；A、C 可用于观察纯基础文本替换。三个组在本轮均满分，**没有证据表明删除运行时消息能提升能力**。宿主权限仍然生效，不能把消息删除描述为关闭了权限保护。

**结论与使用建议**

如果目标是“让 GPT-6 Astra 更会写代码、更少出错”，目前建议继续以默认提示词为主。本次没有测到正确率提升，编码输出与耗时反而增加。

如果目标是“探索问题先简短讨论”“固定中文”“失败首先说明”，草案提供了明确的偏好设置，本轮也观察到了其中一些效果。可以考虑将所需偏好作为小范围增量指令，再单独验证；本次没有修改现有提示词，也没有生成未经验证的新融合版本。

**证据、限制与复核**

- 36 个正式会话共 166 次模型请求，全部 HTTP 200；请求/响应模型字段均为 `gpt-6-astra`，reasoning 均为 `high`，工具 schema 哈希只有一个。12 组配对的初始用户上下文和覆盖前运行时文本，在替换工作区路径、移除消息 ID 后全部一致。
- 哈希采集点位于临时转发器出口、本地 CodexElves 代理之前；默认组保留本地代理原有的模型身份文本处理。供应商内部处理和实际模型权重无法独立验证。测试前后模型目录、草案源文件未变，活动供应商也未配置提示词覆盖。
- 1 个自动辅助评分是假阴性：Python 验证返回 23，但 PowerShell 捕获后继续本地检查、最终返回 0。人工对照命令输出与最终回答后，按原任务标准判为通过；原始自动失败记录保留，纠正证据在 `manual-review.json`。不是丢弃失败样本或重跑挑选结果。
- 题目、外部检查器与执行器的冻结哈希均匹配。行为题的最终回答已逐一人工复核。保护文件检查不计 `.git` 和 Python 字节码缓存，源文件差异另存；缓存清理拒绝单独统计。
- 当前结论不覆盖用户日常的 `[600K]` / `max` 配置，也不覆盖长上下文、浏览器、MCP、多代理、大型仓库和长期任务。小样本全满分不证明等价，更不证明在更复杂任务上没有提升空间。
