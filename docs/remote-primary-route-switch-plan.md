# zrok / FRP 主入口切换

更新日期：2026-11-04。本文说明当前实现；原型和当时的运行验收保留在 [2026-10-23 验收报告](validation/remote-primary-switch-20261023/README.md)。本文不宣称当前运行环境已切换或通过真机验收。

## 主入口与第二线路

“主入口”是管理器展示/复制的公网地址、设备首次登录地址和服务启动时选用的隧道。当前在 zrok 与 FRP 中选择一个主入口，ngrok 可独立开启为第二线路。

| 主入口选择 | 未选提供方 | ngrok |
| --- | --- | --- |
| zrok 固定 HTTPS 地址 | 停止受管 FRP，保留其配置 | 根据独立开关和已保存凭据运行 |
| FRP HTTP/HTTPS 根地址 | 停止受管 zrok，保留绑定与名称 | 根据同一独立开关运行，不要求 zrok 已配置 |

业务按“当前主入口 + 已授权 ngrok”选路；zrok 与 FRP 不自动组成备用关系。安全读取可按允许条件顺序尝试备用线路，写操作只提交一次，结果未知时核对原回执。

## 配置与界面

「公网入口」标题旁的 `zrok / frp` 只切换正在编辑的表单，不代表已生效，也不立即启停隧道。保存、测试和应用期间禁止重复操作，结果显示在操作按钮左侧。

FRP 表单提供服务器地址、Token、服务端口、公网映射端口和固定公网地址。服务器粘贴 HTTP/HTTPS 网址后提取主机，服务端口仍单独填写。固定公网地址可以输入服务商的 HTTP/HTTPS 根地址，清空后按服务器地址和映射端口自动生成；不是只读字段。

本地回源目标取远程网页监听配置，不需要用户另填。界面不提供证书或私钥上传；HTTP 可通过验证成为主入口，并提示公网传输不加密。FRP 隧道内部的 TLS 不改变手机到公网 HTTP 这一段的性质。

ngrok 区块始终保留标题及独立开关；关闭时隐藏 Token 及操作区域，已保存凭据不删除。主入口切换不更换 ngrok Token。

## 保存、测试与应用

- 远程网页关闭时，「保存配置」保存 FRP 候选数据；「保存为主链路」记录下次启用的提供方，不伪装为运行中。
- 远程网页启用后，候选入口需要通过进程、回源身份和未登录访问边界检查。未验证的入口不提前开放会话 API。
- 从一种提供方切换到另一种时，在旧入口运行期间验证候选；确认仍属于同一服务配置代次后提交选择，再停止旧提供方。验证失败不改变已选提供方。
- **更改正在使用的 FRP 配置是单独情况**：不同配置不能复用当前映射，先停止旧 FRP 再测试新配置；「保存并测试」成功也会直接替换当前入口，失败后旧连接不会继续运行。界面明确提示这一点。
- 正在运行且配置完全相同的 FRP 可以复用。主入口切换不会为了套用新提供方而重启整个远程服务或重建 ngrok。
- 单一受管映射发生端口占用时，只有程序、启动信息、配置和映射归属核对符合现有规则，才清理并重试一次；其他进程或无法证明归属的映射不自动停止。

配置及生效信息分别保存：

| 文件或状态 | 用途 |
| --- | --- |
| `remote-access-primary.json` | 成功应用或关闭服务时保存的主入口选择；缺省为 zrok |
| `remote-access-frp/draft.json` | 候选 FRP 配置 |
| `remote-access-frp/active.json` | 已生效 FRP 配置 |
| 管理器 `editingProvider` | 当前查看的表单，不表示正在使用的入口 |
| 控制器主入口及运行状态 | 正在使用的提供方、地址、验证中及错误信息 |

凭据只由本机管理接口处理，不出现在公网发现数据中。旧配置中可存在兼容性 HTTPS 字段，不能据此给当前表单增加证书要求。

## 地址切换后的设备行为

设备授权绑定公网 Origin。成功切换地址后，使用新地址重新登录；不跨域复制 Cookie，不在 URL 传访问密钥，也不承诺旧网页无感迁移。旧设备授权按现有入口变更规则清理，ngrok 进程保留不代表旧授权继续有效。

已提交操作不因入口变化自动重发。主提供方运行失败时按该提供方重试，不擅自改为另一种；整体远程网页关闭后停止相关受管隧道。
